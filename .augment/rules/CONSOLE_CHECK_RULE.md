# 🚨 CONSOLE CHECK RULE - КРИТИЧЕСКОЕ ПРАВИЛО

**Версия**: 1.0  
**Дата**: 2025-11-08  
**Применение**: ОБЯЗАТЕЛЬНО во всех разговорах Augment Chat и Agent

---

## ⚠️ ГЛАВНОЕ ПРАВИЛО

**ВСЕГДА проверять консоль браузера ПЕРЕД продолжением работы!**

Никогда не продолжать работу если есть красные ошибки в консоли или IDE.

---

## 🔄 ОБЯЗАТЕЛЬНЫЙ ПРОЦЕСС

После КАЖДОГО изменения кода:

```
1. ✅ Редактирую код
   ↓
2. ✅ npm run build (проверка синтаксиса)
   ↓
3. ✅ npm run dev (запуск сервера)
   ↓
4. ✅ Открываю браузер: http://localhost:3000 или любой запущеный порт из консоли
   ↓
5. ✅ анализируй консоль
   ↓
6. ✅ Проверяю: 0 ошибок?
   ├─ ДА → продолжаю работу
   └─ НЕТ → исправляю НЕМЕДЛЕННО
   ↓
7. ✅ ТОЛЬКО ПОТОМ переходу к следующей задаче
```

---

## 🎯 ЧТО ПРОВЕРЯТЬ

### **В консоли браузера (F12 → Console)**:
- ❌ Красные ошибки (Errors)
- ❌ Оранжевые предупреждения (Warnings)
- ❌ ReferenceError
- ❌ TypeError
- ❌ SyntaxError

### **В IDE**:
- ❌ Красные волнистые линии (errors)
- ❌ TypeScript ошибки
- ❌ Lint ошибки

---

## 🚫 ЗАПРЕТЫ

- ❌ НЕ продолжать работу с ошибками в консоли
- ❌ НЕ игнорировать красные ошибки
- ❌ НЕ переходить к следующей задаче без проверки
- ❌ НЕ коммитить код с ошибками

---

## ✅ ПРИМЕРЫ ПРАВИЛЬНОГО ПРОЦЕССА

### ✅ ПРАВИЛЬНО:
```
1. Изменил код в ReportsScreen.tsx
2. npm run build → ✅ успешен
3. npm run dev → ✅ запущен
4. Открыл браузер
5. F12 → Console → 0 ошибок ✅
6. Продолжаю работу
```

### ❌ НЕПРАВИЛЬНО:
```
1. Изменил код в ReportsScreen.tsx
2. npm run build → ✅ успешен
3. npm run dev → ✅ запущен
4. ❌ НЕ проверил консоль
5. ❌ Продолжил работу
6. ❌ Пользователь нашел ошибку
```

---

## 💡 ПОЧЕМУ ЭТО ВАЖНО

- **Ошибки накапливаются** - если не проверить сразу, будет 10 ошибок
- **Сложнее отладить** - чем больше ошибок, тем сложнее найти причину
- **Пользователь видит сломанное приложение** - плохой опыт
- **Теряется время** - на отладку потом уходит в 10 раз больше времени

---

## 🎓 ЗАПОМНИТЬ

**Это как ехать на машине с горящей лампочкой на панели - нужно остановиться и проверить!**

Проверка консоли занимает 10 секунд, а отладка ошибок - 10 минут.
