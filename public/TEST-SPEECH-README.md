# Web Speech API Mobile Testing Guide

## 🎯 Цель

Протестировать Web Speech API на мобильных браузерах и найти root cause почему текст не передается в чат.

## 📱 Способы тестирования

### Способ 1: Локальная сеть (РЕКОМЕНДУЕТСЯ)

1. **Запустить dev server:**
   ```bash
   npm run dev
   ```

2. **Найти локальный IP адрес:**
   
   **macOS/Linux:**
   ```bash
   ifconfig | grep "inet " | grep -v 127.0.0.1
   ```
   
   **Windows:**
   ```bash
   ipconfig
   ```
   
   Пример: `192.168.1.100`

3. **Открыть на телефоне:**
   ```
   http://192.168.1.100:5173/test-speech.html
   ```
   
   ⚠️ **ВАЖНО:** Телефон и компьютер должны быть в одной Wi-Fi сети!

### Способ 2: Vercel Deployment

1. **Закоммитить и запушить:**
   ```bash
   git add public/test-speech.html
   git commit -m "test: Add Web Speech API test page"
   git push origin main
   ```

2. **Открыть на телефоне:**
   ```
   https://unity-wine.vercel.app/test-speech.html
   ```

### Способ 3: ngrok (если локальная сеть не работает)

1. **Установить ngrok:**
   ```bash
   brew install ngrok  # macOS
   # или скачать с https://ngrok.com/download
   ```

2. **Запустить туннель:**
   ```bash
   npm run dev  # в одном терминале
   ngrok http 5173  # в другом терминале
   ```

3. **Открыть URL из ngrok на телефоне:**
   ```
   https://xxxx-xx-xx-xx-xx.ngrok-free.app/test-speech.html
   ```

## 🧪 Тестовые сценарии

### Тест 1: Базовая функциональность

1. Открыть `test-speech.html` на телефоне
2. Проверить что "Поддержка Web Speech API" = ✅ Поддерживается
3. Нажать "Начать запись"
4. Сказать "Привет, это тест"
5. Подождать 2-3 секунды
6. Проверить:
   - ✅ Статус записи = "🔴 ЗАПИСЬ ИДЕТ"
   - ✅ В логе появились события `onstart`, `onsoundstart`, `onspeechstart`
   - ✅ В логе появились события `onresult`
   - ✅ В "Распознанный текст" появился текст
   - ✅ В "Последний результат" показаны детали (isFinal, confidence, text)

### Тест 2: Interim Results

1. Включить "Interim Results" (должно быть включено по умолчанию)
2. Нажать "Начать запись"
3. Медленно сказать "Раз два три четыре пять"
4. Проверить:
   - ✅ В логе появляются INTERIM RESULT во время речи
   - ✅ В логе появляется FINAL RESULT после паузы
   - ✅ Текст обновляется в реальном времени

### Тест 3: Без Interim Results

1. Выключить "Interim Results"
2. Нажать "Начать запись"
3. Сказать "Привет, это тест"
4. Проверить:
   - ✅ В логе НЕТ INTERIM RESULT
   - ✅ В логе появляется только FINAL RESULT
   - ✅ Текст появляется только после паузы

### Тест 4: Continuous Mode

1. Включить "Continuous"
2. Нажать "Начать запись"
3. Сказать "Первая фраза" → пауза → "Вторая фраза" → пауза → "Третья фраза"
4. Проверить:
   - ✅ Запись НЕ останавливается после первой фразы
   - ✅ Все три фразы распознаются
   - ✅ В логе несколько FINAL RESULT

### Тест 5: Разные языки

1. Выбрать "English (en-US)"
2. Нажать "Начать запись"
3. Сказать "Hello, this is a test"
4. Проверить:
   - ✅ Текст распознается на английском
   - ✅ В логе появляется FINAL RESULT

## 🔍 Что делать с результатами

### Если НЕТ onresult вообще:

**Причина:** Web Speech API не работает на этом браузере/устройстве

**Решение:**
1. Проверить что HTTPS (или localhost)
2. Проверить разрешения микрофона
3. Попробовать другой браузер (Chrome вместо Safari)
4. Рассмотреть fallback на MediaRecorder API + server-side transcription

### Если ТОЛЬКО interim results, НЕТ final:

**Причина:** Это ИМЕННО наша проблема! Mobile Safari не отправляет isFinal=true

**Решение:** ✅ УЖЕ РЕАЛИЗОВАНО в коммите `b3ead7d`
- Используем флаг `hasFinalResult`
- В `onend` проверяем: если НЕ было final но есть lastTranscript → используем его

### Если есть FINAL result но текст НЕ передается в чат:

**Причина:** Проблема в React компоненте, НЕ в Web Speech API

**Решение:**
1. Проверить что `setTranscript()` вызывается
2. Проверить что `useEffect` в VoicePoweredOrb срабатывает
3. Проверить что `onTranscriptReady()` вызывается
4. Проверить что родительский компонент получает текст
