## 🚨 ТИПИЧНЫЕ ОШИБКИ

### **ReferenceError: Cannot access before initialization**
```
Причина: Функция используется ДО её определения
Решение: Обернуть в useCallback и переместить ПЕРЕД useEffect
```

### **TypeError: Cannot read property of undefined**
```
Причина: Переменная не инициализирована
Решение: Проверить инициализацию в useState
```

### **SyntaxError: Unexpected token**
```
Причина: Ошибка в синтаксисе кода
Решение: Проверить скобки, кавычки, точки с запятой
```

## 💡 ПОЧЕМУ ЭТО РАБОТАЕТ

1. **npm run build** - проверяет синтаксис (статический анализ)
2. **npm run dev** - запускает сервер (компиляция)
3. **Браузер + F12** - проверяет runtime ошибки (динамический анализ)

**Вывод**: Нужны ВСЕ три шага!
