## 🎯 Обзор

Система книг UNITY — это **эмоциональное ядро** приложения, позволяющее пользователям превращать свои записи в персонализированные PDF-книги с фотографиями, достижениями и красивым дизайном.

## ✅ Что реализовано

### Фаза 1: Flow и UX ✅

#### 1.1. Визард создания книги (4 шага)

**Файл**: `src/features/mobile/reports/components/book-creation-wizard/`

**Шаги**:

1.  **Step 1: Выбор периода**
    *   Пользователь выбирает начало и конец периода через date picker.
    *   Валидация: минимум 5 записей требуется.
    *   Подсказка: "Выберите период с достаточным количеством записей".

2.  **Step 2: Выбор контекстов (категорий)**
    *   Автоматически загружаются доступные категории из записей пользователя.
    *   Можно выбрать несколько категорий или оставить пусто (все записи).
    *   Кнопки "Выбрать все" / "Очистить".

3.  **Step 3: Выбор стиля**
    *   3 стиля: Теплый семейный 🏡, Биографический 📖, Мотивационный 🚀.
    *   **Визуальное превью**: Мини-карточка с примером страницы для каждого стиля.
    *   Цвета и фон превью соответствуют стилю.

4.  **Step 4: Выбор макета**
    *   3 макета: Фото + текст 📸, Только текст 📝, Минималистичный ✨.
    *   **Визуальное превью**: Схематическое отображение макета страницы.
    *   Подсказка на последнем шаге про черновик и финальный PDF.

**После генерации**:
*   Показывается модалка успеха `BookCreationSuccessModal` с конфетти.
*   Два CTA:
    *   **Primary**: "Перейти к редактору книги" → открывает `BookDraftEditor`.
    *   **Secondary**: "Перейти на полку книг" → открывает `BooksLibraryScreen`.

#### 1.2. Редактор книги

**Файл**: `src/features/mobile/reports/components/BookDraftEditor.tsx`

**Возможности**:
*   Редактирование названия, подзаголовка, вступления.
*   Редактирование глав (название + content).
*   **Загрузка фото к главам** (только для layout `photo_text`):
    *   Drag & drop или клик на "Добавить".
    *   Миниатюры с возможностью удаления.
*   **Предпросмотр PDF** в реальном времени.
*   **Кнопка "Создать финальную версию"**: генерирует PDF и сохраняет в Storage.

**После создания PDF**:
*   Возврат на полку с обновлением списка.
*   Книга меняет статус на "Готово (PDF доступен)".

#### 1.3. Полка книг

**Файл**: `src/features/mobile/reports/components/BooksLibraryScreen.tsx`

**Дизайн**:
*   **Сетка обложек** (grid): 1 колонка на мобильном, 2-3 на планшете.
*   Каждая книга — красивая обложка:
    *   Фоновый градиент по стилю книги.
    *   Миниатюра обложки с emoji и названием.
    *   Бейдж статуса в углу.
    *   Версия (`v2`, `v3`) на обложке, если >1.

**Фильтры**:
*   Все / Черновики / Готовые.

**Действия**:
*   Для **черновиков**:
    *   "Редактировать черновик" → открывает редактор.
    *   Хинт: "Сначала создай финальную PDF-версию в редакторе".
*   Для **готовых книг**:
    *   "Просмотр" → открывает PDF в новой вкладке.
    *   "Скачать" → скачивает PDF.
    *   "Создать новую версию" → клонирует книгу как новый черновик.
    *   Удаление (с подтверждением).

**Информация на карточке**:
*   Название, период, стиль.
*   Количество записей, страниц, достижений.

### Фаза 4: Расширения (Фото, Достижения, Авто-генерация) ✅

#### 4.1. Фото-книги

**База данных**:
*   Таблица `book_photos` (book_id, chapter_index, photo_url, caption).
*   Storage bucket `book-photos` с RLS политиками.
*   Миграция: `create_book_photos_table`.

**Автоматическая привязка фото**:
*   Edge Function `books-generate-draft` теперь:
    *   Собирает фото из записей (`media` поле).
    *   Передает AI список записей с `id`.
    *   AI возвращает `source_entry_ids` для каждой главы.
    *   Функция автоматически создает записи в `book_photos`, привязывая фото к нужным главам.

**Редактор**:
*   Для layout `photo_text` появляется секция "Фотографии" под каждой главой.
*   Можно загружать дополнительные фото (drag & drop или клик).
*   Миниатюры с кнопкой удаления.

**PDF**:
*   Фото рендерятся в главах (перед текстом).
*   С подписями (caption = дата записи по умолчанию).

#### 4.2. Глава достижений

**Логика**:
*   При генерации книги собираются все записи с `is_achievement = true`.
*   Формируется массив `achievementsSummary` (id, date, category, summary).
*   Сохраняется в `metadata.achievements`.

**PDF**:
*   Отдельная глава "Достижения за период" после основных глав.
*   Список достижений с bullet points.

**Полка**:
*   На карточке книги отображается `🏆 N достижений`.

#### 4.3. Автоматическая генерация

**Edge Function**: `books-generate-monthly-auto`

**Логика**:
1.  Вычисляет период (прошлый месяц).
2.  Находит всех Premium пользователей.
3.  Для каждого проверяет:
    *   Есть ли книга за этот период? → Пропускает.
    *   Достаточно ли записей (минимум 5)? → Если нет, пропускает.
4.  Вызывает `books-generate-draft` через HTTP.
5.  (TODO) Отправляет Push-уведомление "Твоя книга за месяц готова! 📖".

**Cron задача**:
*   Расписание: `0 9 1 * *` (9:00 утра, 1-е число месяца).
*   Миграция: `schedule_monthly_books_generation`.

#### 4.4. Оглавление в PDF

**Реализация**:
*   Отдельная страница в начале PDF после титульного листа.
*   Список всех глав с нумерацией.
*   Включает главу достижений (если есть).

## 🔄 Полный User Flow

### Сценарий 1: Создание первой книги

1.  Пользователь открывает **Отчеты** → нажимает "Открыть полку книг".
2.  Видит пустую полку → нажимает "Создать книгу".
3.  **Визард**:
    *   Шаг 1: Выбирает период (например, последний месяц).
    *   Шаг 2: Выбирает категории (например, "Работа", "Семья") или оставляет все.
    *   Шаг 3: Выбирает стиль — видит превью каждого, выбирает "Теплый семейный 🏡".
    *   Шаг 4: Выбирает макет — видит схему, выбирает "Фото + текст 📸".
    *   Читает подсказку: "Сейчас будет создан черновик. Далее можно отредактировать и сохранить PDF."
    *   Нажимает "Создать книгу".
4.  **Генерация**:
    *   Показывается прогресс (анимация).
    *   Edge Function генерирует AI-текст и собирает фото из записей.
5.  **Модалка успеха** (с конфетти):
    *   "Книга создана! 🎉"
    *   Пользователь нажимает **"Перейти к редактору книги"**.
6.  **Редактор**:
    *   Видит сгенерированный текст (название, главы).
    *   Видит автоматически привязанные фото под главами.
    *   Может добавить еще фото или подправить текст.
    *   Переключается на вкладку "Предпросмотр" → видит полный PDF с оглавлением.
    *   Нажимает **"Создать финальную версию"**.
7.  **PDF создан**:
    *   Редактор закрывается, открывается полка.
    *   Книга теперь со статусом **"Готово (PDF доступен)"**.
    *   Доступны кнопки "Просмотр" и "Скачать".

### Сценарий 2: Редактирование готовой книги

1.  Пользователь видит книгу на полке.
2.  Нажимает **"Создать новую версию"**.
3.  Подтверждает: "Мы создадим копию. Оригинал сохранится."
4.  Открывается редактор с копией книги (версия `v2`).
5.  Пользователь вносит изменения, добавляет новые фото.
6.  Создает финальный PDF v2.
7.  На полке теперь две книги: оригинал (v1) и новая версия (v2).

### Сценарий 3: Автоматическая генерация (Premium)

1.  1-го числа месяца в 9:00 утра запускается Cron.
2.  Функция `books-generate-monthly-auto` находит Premium пользователей.
3.  Для каждого:
    *   Проверяет, есть ли книга за прошлый месяц.
    *   Если нет и есть минимум 5 записей → генерирует книгу.
    *   Отправляет Push: "Твоя книга за месяц готова! 📖".
4.  Пользователь получает уведомление, заходит в приложение.
5.  На полке видит новую книгу (черновик).
6.  Может сразу скачать или отредактировать.

## 🗂️ Структура данных

### Таблица `books_archive`

```sql
CREATE TABLE books_archive (
  id UUID PRIMARY KEY,
  user_id UUID NOT NULL REFERENCES profiles(id),
  parent_book_id UUID REFERENCES books_archive(id), -- ✅ NEW: For versioning
  version INTEGER DEFAULT 1, -- ✅ NEW: Version number
  period_start DATE NOT NULL,
  period_end DATE NOT NULL,
  contexts TEXT[], -- Categories filter
  style TEXT NOT NULL, -- warm_family | biographical | motivational
  layout TEXT NOT NULL, -- photo_text | text_only | minimal
  theme TEXT DEFAULT 'light',
  story_json JSONB NOT NULL, -- AI-generated book structure
  metadata JSONB, -- Stats, achievements, diary info
  pdf_url TEXT, -- Final PDF in Storage
  is_draft BOOLEAN DEFAULT true,
  is_final BOOLEAN DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### Таблица `book_photos`

```sql
CREATE TABLE book_photos (
  id UUID PRIMARY KEY,
  book_id UUID NOT NULL REFERENCES books_archive(id) ON DELETE CASCADE,
  chapter_index INTEGER NOT NULL, -- 0-based
  photo_url TEXT NOT NULL,
  caption TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### `story_json` структура

```typescript
{
  title: string,
  subtitle: string,
  prologue: string,
  chapters: [
    {
      title: string,
      content: string,
      highlights: string[],
      source_entry_ids: string[] // ✅ NEW: For photo mapping
    }
  ],
  epilogue: string,
  dedication?: string
}
```

### `metadata` структура

```typescript
{
  entriesCount: number,
  achievementsCount: number,
  achievements: [ // ✅ NEW: For achievements chapter
    {
      id: string,
      date: string,
      category: string,
      summary: string
    }
  ],
  tokensUsed: number,
  estimatedCost: number,
  diaryName: string,
  diaryEmoji: string,
  pages?: number,
  wordCount?: number
}
```

## 🚀 API Endpoints

### 1. POST `/books-generate-draft`

**Назначение**: Генерация черновика книги с AI

**Request**:
```json
{
  "userId": "uuid",
  "periodStart": "2025-10-01",
  "periodEnd": "2025-10-31",
  "contexts": ["работа", "семья"],
  "style": "warm_family",
  "layout": "photo_text",
  "theme": "light",
  "diaryName": "Мой дневник",
  "diaryEmoji": "🏆"
}
```

**Response**:
```json
{
  "success": true,
  "draftId": "uuid",
  "storyJson": { ... },
  "estimatedPages": 12
}
```

**Что делает**:
1.  Проверяет кэш (токены экономятся!).
2.  Загружает записи за период.
3.  Собирает фото из записей.
4.  Собирает достижения.
5.  Вызывает OpenAI GPT-4o-mini для генерации книги.
6.  Сохраняет черновик в `books_archive`.
7.  Автоматически создает записи в `book_photos` для фото.

### 2. PUT `/books-render-pdf/:draftId/upload`

**Назначение**: Рендер финального PDF и загрузка в Storage

**Request**:
```json
{
  "pdfBlob": "base64...",
  "pages": 15,
  "wordCount": 3500
}
```

**Response**:
```json
{
  "success": true,
  "pdfUrl": "https://..."
}
```

**Что делает**:
1.  Конвертирует base64 → Uint8Array.
2.  Загружает в Storage bucket `books`.
3.  Обновляет `books_archive`:
    *   `pdf_url = URL`
    *   `is_final = true`
    *   `is_draft = false`
    *   `metadata.pages`, `metadata.wordCount`

### 3. POST `/books-generate-monthly-auto`

**Назначение**: Автоматическая генерация книг для Premium (Cron)

**Вызов**: Через pg_cron (расписание `0 9 1 * *`)

**Логика**:
1.  Определяет период (прошлый месяц).
2.  Находит Premium пользователей.
3.  Для каждого:
    *   Проверяет наличие книги.
    *   Проверяет минимум 5 записей.
    *   Вызывает `books-generate-draft`.
    *   (TODO) Отправляет Push.

**Response**:
```json
{
  "success": true,
  "results": {
    "total": 100,
    "generated": 45,
    "skipped": 50,
    "errors": 5
  }
}
```
