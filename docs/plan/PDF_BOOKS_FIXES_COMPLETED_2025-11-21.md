### 2. ✅ Обновлены PDF компоненты для использования переводов

**Файлы**:
- `src/features/mobile/reports/components/BookDraftEditor.tsx`
- `src/features/mobile/reports/components/ReportPDFDocument.tsx`
- `src/features/mobile/reports/components/ReportsScreen.tsx`

**Изменения**:
- Удален хардкод русского языка из PDF компонентов
- Добавлена передача переводов через пропсы (т.к. `@react-pdf/renderer` не поддерживает React контекст)
- Все тексты теперь используют i18n систему

**Пример**:
```typescript
// Было:
<Text>Вступление</Text>

// Стало:
<Text>{translations.prologue}</Text>
```
