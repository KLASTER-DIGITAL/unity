### 2. ✅ Исправление ошибок в BookDraftEditor

**Проблема**: 
- `story.chapters` может быть undefined при редактировании глав
- Отсутствие проверки на undefined при работе с chapters

**Решение**:
```typescript
// Было:
const newChapters = [...story.chapters];

// Стало:
const newChapters = [...(story.chapters || [])];
```

**Файлы**:
- `src/features/mobile/reports/components/BookDraftEditor.tsx` (строки 533, 543)

**Результат**: ✅ Ошибки исправлены, редактор работает корректно
