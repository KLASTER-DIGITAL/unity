## ⏳ Что нужно протестировать

### Тест 1: Создание книги
1. Открыть приложение
2. Авторизоваться
3. Перейти в ReportsScreen
4. Нажать "Полка"
5. Нажать "Создать книгу"
6. Пройти визард (4 шага):
   - Шаг 1: Выбор периода
   - Шаг 2: Выбор контекстов
   - Шаг 3: Выбор стиля
   - Шаг 4: Выбор макета
7. Проверить что книга создана в библиотеке

**Ожидаемый результат**: Книга создана со статусом "Черновик"

### Тест 2: Редактирование книги
1. Открыть книгу в библиотеке
2. Нажать "Редактировать черновик"
3. Изменить:
   - Название книги
   - Подзаголовок
   - Вступление
   - Содержание главы
   - Заключение
4. Нажать "Сохранить"
5. Проверить что изменения сохранены

**Ожидаемый результат**: Изменения сохранены, книга обновлена

### Тест 3: Рендер PDF
1. Открыть книгу в редакторе
2. Перейти на вкладку "Предпросмотр"
3. Дождаться генерации предпросмотра PDF
4. Проверить что предпросмотр отображается корректно
5. Нажать "Создать финальную версию"
6. Дождаться завершения рендера
7. Проверить консоль браузера на ошибки
8. Проверить статус в БД:
   - `is_draft: false`
   - `is_final: true`
   - `pdf_url` заполнен

**Ожидаемый результат**: PDF создан, статусы обновлены, `pdf_url` сохранен

### Тест 4: Просмотр и скачивание
1. Вернуться в библиотеку книг
2. Проверить что книга имеет статус "Готово"
3. Нажать "Просмотр" → проверить что PDF открывается
4. Нажать "Скачать" → проверить что PDF скачивается
5. Проверить содержимое PDF файла

**Ожидаемый результат**: PDF открывается и скачивается корректно

## 📊 Проверка базы данных

### SQL запросы для проверки:

```sql
-- Проверить последнюю созданную книгу
SELECT 
  id, 
  is_draft, 
  is_final, 
  pdf_url IS NOT NULL as has_pdf,
  pdf_url,
  created_at,
  updated_at
FROM books_archive 
ORDER BY created_at DESC 
LIMIT 1;

-- Проверить все книги пользователя
SELECT 
  id,
  is_draft,
  is_final,
  pdf_url IS NOT NULL as has_pdf,
  created_at
FROM books_archive 
WHERE user_id = 'USER_ID'
ORDER BY created_at DESC;
```

### Ожидаемые результаты:
- ✅ После рендера PDF: `is_draft: false`, `is_final: true`, `pdf_url` заполнен
- ✅ `updated_at` обновлен после рендера
