### 2. Edge Function `reports/index.ts`

✅ **Логика работы**:
- Правильно определяет операцию по периоду (`weekly_report` или `monthly_report`)
- Загружает конфигурацию через `getAiOperationConfig()`
- Проверяет доступность операции через `isOperationAvailable()`
- Использует данные из `user_stats_daily` и `user_stats_monthly`
- Интегрирует достижения из `user_achievements`
- Сохраняет результат в `user_reports` с правильной структурой

✅ **Сохранение данных**:
- `ai_summary` сохраняется отдельно (строка)
- `ai_insights` сохраняется как JSONB объект (весь parsed ответ от AI)
- `stats` сохраняется как JSONB snapshot статистики
- Использует `upsert` с `onConflict` для предотвращения дубликатов
