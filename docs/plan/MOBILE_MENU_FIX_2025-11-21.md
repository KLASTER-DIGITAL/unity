# 🔧 Исправление проблемы с мобильным меню — "скачет" при скролле

**Дата**: 2025-11-21  
**Статус**: ✅ ИСПРАВЛЕНО  
**Приоритет**: P0 — КРИТИЧНО

---

## 🐛 Проблема

Мобильное меню навигации "скачет" при скролле на телефоне — не фиксировано на своем месте.

**Симптомы**:
- Меню меняет позицию при скролле страницы
- Видимые "скачки" меню вверх/вниз
- Нестабильное поведение на мобильных устройствах

---

## 🔍 Причина проблемы

### 1. Логика scroll detection ❌

**Файл**: `src/shared/components/layout/MobileBottomNav.tsx`

**Проблема**: Была логика, которая меняла позицию меню при скролле:
```tsx
const [isScrolledDown, setIsScrolledDown] = useState(false);

useEffect(() => {
  const handleScroll = () => {
    const isNearBottom = scrollTop + windowHeight >= documentHeight - 100;
    setIsScrolledDown(isNearBottom);
  };
  window.addEventListener('scroll', handleScroll);
}, []);

// Позиция менялась в зависимости от isScrolledDown:
stickyBottom
  ? 'bottom-0'
  : isScrolledDown
    ? 'bottom-8'  // ❌ Менялось с bottom-4 на bottom-8
    : 'bottom-4'
```

**Результат**: Меню "скакало" между `bottom-4` (16px) и `bottom-8` (32px) при скролле.

---

### 2. Невалидный z-index ❌

**Проблема**: Использовался `z-9999` (невалидный Tailwind класс):
```tsx
'fixed left-1/2 z-9999 -translate-x-1/2'
```

Tailwind не поддерживает такие большие значения по умолчанию.

---

### 3. Отсутствие оптимизации для мобильных устройств ❌

**Проблема**: На мобильных устройствах viewport height может меняться при скролле (из-за адресной строки браузера), что вызывает рефлоу и "скачки".

---

## ✅ Исправления

### 1. Убрана логика scroll detection ✅

**Было**:
```tsx
const [isScrolledDown, setIsScrolledDown] = useState(false);

useEffect(() => {
  const handleScroll = () => {
    const isNearBottom = scrollTop + windowHeight >= documentHeight - 100;
    setIsScrolledDown(isNearBottom);
  };
  window.addEventListener('scroll', handleScroll);
}, []);
```

**Стало**:
```tsx
// ✅ FIX: Убрана логика scroll detection - меню всегда фиксировано на одном месте
```

**Результат**: Меню больше не меняет позицию при скролле.

---

### 2. Фиксированная позиция ✅

**Было**:
```tsx
stickyBottom
  ? 'bottom-0'
  : isScrolledDown
    ? 'bottom-8'  // ❌ Менялось
    : 'bottom-4'
```

**Стало**:
```tsx
// ✅ FIX: Фиксированная позиция - меню всегда на одном месте
stickyBottom ? 'bottom-0' : 'bottom-4'
```

**Результат**: Меню всегда на одном месте (`bottom-4` для floating режима или `bottom-0` для sticky).

---

### 3. Исправлен z-index ✅

**Было**:
```tsx
'fixed left-1/2 z-9999 -translate-x-1/2'
```

**Стало**:
```tsx
'fixed left-1/2 z-[9999] -translate-x-1/2'
```

**Результат**: Валидный кастомный z-index класс.

---

### 4. Оптимизация для мобильных устройств ✅

**Добавлено**:
```tsx
style={{
  // ✅ FIX: Оптимизация для предотвращения скачков на мобильных устройствах
  // transform: translateZ(0) создает новый слой композиции, предотвращая рефлоу
  transform: isKeyboardVisible
    ? 'translateY(100%) translateZ(0)'
    : 'translateY(0) translateZ(0)',
  // will-change оптимизирует анимации (только когда клавиатура видна)
  willChange: isKeyboardVisible ? 'transform' : 'auto',
  // opacity для плавного скрытия/показа
  opacity: isKeyboardVisible ? 0 : 1,
}}
```

**Результат**:
- `translateZ(0)` создает новый слой композиции, предотвращая рефлоу
- `will-change` оптимизирует анимации
- Меню рендерится на отдельном слое и не "скачет"

---

### 5. Упрощены transitions ✅

**Было**:
```tsx
'transition-all duration-300',
isKeyboardVisible ? 'translate-y-full opacity-0' : 'translate-y-0 opacity-100'
```

**Стало**:
```tsx
'transition-opacity duration-300'
// transform и opacity управляются через style
```

**Результат**: Более точный контроль через inline styles.

## 📝 Примечания

1. **Почему `translateZ(0)`**: Создает новый слой композиции в GPU, предотвращая рефлоу и "скачки" при изменении viewport height на мобильных устройствах.

2. **Почему `will-change`**: Оптимизирует анимации, но только когда клавиатура видна (когда действительно нужна анимация).

3. **Почему убрали scroll detection**: Меню должно быть всегда фиксировано на одном месте. Если нужно поднимать меню при скролле вниз, это должно быть отдельной фичей с более стабильной логикой.
