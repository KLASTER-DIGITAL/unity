**Файл**: `src/features/mobile/reports/components/BookGenerationProgress.tsx`

**Было**:
```tsx
<div className="bg-linear-to-r mx-auto mb-4 flex h-16 w-16 items-center justify-center rounded-full from-purple-600 to-blue-600">
```

**Стало**:

## 🔄 Проверка User Flow

### Сценарий 1: Создание первой книги ✅

1. ✅ Пользователь открывает **Отчеты** → нажимает "Открыть полку книг"
2. ✅ Видит пустую полку → нажимает "Создать книгу"
3. ✅ **Визард**:
   - Шаг 1: Выбирает период
   - Шаг 2: Выбирает категории (или оставляет все)
   - Шаг 3: Выбирает стиль (видит превью)
   - Шаг 4: Выбирает макет (видит схему)
   - Нажимает "Создать книгу"
4. ✅ **Генерация**:
   - Показывается прогресс (анимация)
   - Edge Function генерирует AI-текст и собирает фото
5. ✅ **Модалка успеха** (с конфетти):
   - "Книга создана! 🎉"
   - Пользователь нажимает **"Перейти к редактору книги"**
6. ✅ **Редактор**:
   - Видит сгенерированный текст
   - Видит автоматически привязанные фото
   - Может добавить еще фото или подправить текст
   - Переключается на "Предпросмотр" → видит полный PDF
   - Нажимает **"Создать финальную версию"**
7. ✅ **PDF создан**:
   - Редактор закрывается, открывается полка
   - Книга теперь со статусом **"Готово (PDF доступен)"**
   - Доступны кнопки "Просмотр" и "Скачать"

**Статус**: ✅ FLOW РАБОТАЕТ КОРРЕКТНО
