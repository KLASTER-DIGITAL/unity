  - Подзаголовок: пустое поле
  - Вступление: пустое поле
- Секция "Главы" пустая

**Причина найдена**:
✅ Данные `story_json` загружаются из базы данных, но имеют **неправильную структуру**

**Проблема**:
В базе данных хранится старый формат отчета вместо структуры книги:
```json
{
  "title": "...",
  "summary": "...",
  "insights": "...",
  "transformations": "..."
}
```

**Ожидаемая структура** (для книг):
```json
{
  "title": "...",
  "subtitle": "...",
  "prologue": "...",
  "chapters": [
    {
      "title": "...",
      "content": "...",
      "highlights": [...]
    }
  ],
  "epilogue": "...",
  "dedication": "..."
}
```

**Вывод**: Edge Function `books-generate-draft` использует AI операцию `monthly_report`, которая генерирует старый формат отчета вместо структуры книги.

## 🔍 Обнаруженные проблемы

### 1. ⚠️ ПРОБЛЕМА: Неправильный формат `story_json`

**Приоритет**: P0 — КРИТИЧНО  
**Статус**: Обнаружено, требует исправления

**Описание**:
Edge Function `books-generate-draft` использует AI операцию `monthly_report` из базы данных, которая генерирует старый формат отчета (summary, insights, transformations) вместо структуры книги (chapters, prologue, epilogue).

**Корневая причина**:
- AI операция `monthly_report` предназначена для генерации отчетов, а не книг
- Edge Function использует эту операцию для генерации книг
- Результат: неправильная структура данных в `story_json`

**Решение**:
1. **Создать новую AI операцию** `book_generation` специально для генерации книг
2. **Обновить Edge Function** `books-generate-draft` для использования новой AI операции
3. **Или обновить существующую AI операцию** `monthly_report` для поддержки формата книг

**Приоритет**: P0 — КРИТИЧНО (блокирует работу редактора)

**Оценка времени**: 1-2 часа

**Файлы для изменения**:
- `supabase/functions/books-generate-draft/index.ts` (строки 266-340)
- Создать новую AI операцию в таблице `ai_operations` с ID `book_generation`
