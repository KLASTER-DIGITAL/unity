### 3. ✅ Реализовано применение настроек визарда в PDF

**Проблема**: PDF генерировался без учета настроек из визарда (layout, style, theme).

**Решение**: Создана система динамических стилей PDF в зависимости от настроек.

#### 3.1. Layout (Макет)

**Реализовано**:
- **`photo_text`**: Секции с фоном, рамками и отступами (для фото + текст)
- **`text_only`**: Минималистичный дизайн с цветной левой границей
- **`minimal`**: Лаконичный дизайн с минимальными отступами и разделителями

**Код**: `createPDFStyles()` функция в `BookDraftEditor.tsx`

#### 3.2. Style (Стиль)

**Реализовано**:
- **`warm_family`**: Теплые цвета (красный), курсивный подзаголовок, увеличенный line-height
- **`biographical`**: Холодные цвета (синий), строгий стиль
- **`motivational`**: Энергичные цвета (оранжевый), яркий акцент

**Цвета**:
```typescript
warm_family:   accentColor = '#E63946' (красный)
biographical:  accentColor = '#1E88E5' (синий)
motivational:  accentColor = '#FF9800' (оранжевый)
```

#### 3.3. Theme (Тема)

**Реализовано**:
- **`light`**: Светлый фон (#FFFFFF), темный текст (#333333)
- **`dark`**: Темный фон (#1a1a1a), светлый текст (#E5E5E5)

**Применение**: Все цвета адаптируются под тему (фон, текст, границы, акценты)

---

### 4. ✅ Загрузка настроек из базы данных

**Реализовано**:
- Загрузка `layout`, `style`, `theme` из `books_archive` при открытии редактора
- Передача настроек в компонент `BookPDF`
- Применение настроек при генерации PDF

**Код**:
```typescript
const { data } = await supabase
  .from('books_archive')
  .select('*')
  .eq('id', draftId)
  .single();

setDraft({
  layout: data.layout || 'photo_text',
  style: data.style || 'warm_family',
  theme: data.theme || 'light',
  metadata: data.metadata || null,
});
```

## 🎨 Визуальные различия по настройкам

### Layout различия:

**photo_text**:
- Секции с фоном (#FAFAFA светлая / #252525 темная)
- Рамки вокруг секций
- Отступы 15px внутри секций
- Скругленные углы

**text_only**:
- Цветная левая граница (3px)
- Отступ слева 15px
- Без фона секций
- Фокус на тексте

**minimal**:
- Минимальные отступы (30px вместо 40px)
- Разделители между секциями (border-bottom)
- Уменьшенные размеры шрифтов
- Максимальная лаконичность

### Style различия:

**warm_family**:
- Красный акцент (#E63946)
- Курсивный подзаголовок
- Увеличенный line-height (1.8)
- Теплый фон секций (#FFF5F5)

**biographical**:
- Синий акцент (#1E88E5)
- Строгий стиль
- Стандартный line-height (1.6)
- Холодный фон секций (#F5F9FF)

**motivational**:
- Оранжевый акцент (#FF9800)
- Энергичный стиль
- Стандартный line-height (1.6)

## 📝 Технические детали

### Структура данных

**books_archive таблица**:
```sql
layout: 'photo_text' | 'text_only' | 'minimal'
style: 'warm_family' | 'biographical' | 'motivational'
theme: 'light' | 'dark'
```

**Передача в компонент**:
```typescript
<BookPDF
  story={story}
  metadata={draft?.metadata ?? {}}
  translations={...}
  settings={{
    layout: draft?.layout || 'photo_text',
    style: draft?.style || 'warm_family',
    theme: draft?.theme || 'light',
  }}
/>
```

### Функция создания стилей

**Логика**:
1. Определение базовых цветов (тема)
2. Выбор акцентного цвета (стиль)
3. Применение layout-специфичных стилей
4. Создание StyleSheet через `StyleSheet.create()`

**Особенности**:
- Динамическое создание стилей (не статический объект)
- Поддержка темной темы для всех комбинаций
- Адаптация размеров под layout (minimal = меньше)
