## 🎯 Что было исправлено

### 1. ✅ PDF генерируется на языке пользователя

**Проблема**: Все тексты в PDF были захардкожены на русском языке.

**Решение**:
- Создана миграция с переводами для всех текстов PDF (8 языков)
- Обновлены компоненты `BookDraftEditor.tsx` и `ReportPDFDocument.tsx`
- Все тексты теперь используют i18n систему

**Результат**: PDF генерируется на языке пользователя из профиля.

---

### 2. ✅ PDF применяет все настройки из визарда

**Проблема**: PDF генерировался без учета настроек (layout, style, theme).

**Решение**:
- Загрузка настроек из `books_archive` при открытии редактора
- Создана функция `createPDFStyles()` для динамических стилей
- Применение стилей в зависимости от:
  - **Layout**: `photo_text`, `text_only`, `minimal`
  - **Style**: `warm_family`, `biographical`, `motivational`
  - **Theme**: `light`, `dark`

**Результат**: PDF визуально отличается в зависимости от выбранных настроек.

---

### 3. ✅ Edge Function использует настройки при генерации

**Проверено**:
- Edge Function получает `style`, `layout`, `theme` из запроса ✅
- Передает `book_style` в AI промпт через `replacePlaceholders` ✅
- Сохраняет все настройки в `books_archive` ✅

**Результат**: AI генерирует контент с учетом выбранного стиля.

## 📊 Визуальные различия

### Layout (Макет):

| Layout | Описание | Визуальные особенности |
|--------|----------|------------------------|
| `photo_text` | Фото + текст | Фон секций, рамки, отступы 15px |
| `text_only` | Только текст | Цветная левая граница 3px, без фона |
| `minimal` | Минималистичный | Минимальные отступы, разделители |

### Style (Стиль):

| Style | Цвет акцента | Особенности |
|-------|--------------|-------------|
| `warm_family` | #E63946 (красный) | Курсивный подзаголовок, line-height 1.8 |
| `biographical` | #1E88E5 (синий) | Строгий стиль, line-height 1.6 |
| `motivational` | #FF9800 (оранжевый) | Энергичный стиль, яркий акцент |

### Theme (Тема):

| Theme | Фон | Текст | Границы |
|-------|-----|-------|---------|
| `light` | #FFFFFF | #333333 | #E5E5E5 |
| `dark` | #1a1a1a | #E5E5E5 | #333333 |
