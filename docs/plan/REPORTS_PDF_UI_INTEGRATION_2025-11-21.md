## ✅ Выполненные задачи

### 1. ✅ Создан компонент ReportPDFDocument

**Файл**: `src/features/mobile/reports/components/ReportPDFDocument.tsx`

**Функционал**:
- Генерация PDF документа для отчетов
- Использует `@react-pdf/renderer` (как BookPDF)
- Отображает статистику, AI анализ, записи
- Поддержка Premium/Free разделения

### 2. ✅ Добавлена функция экспорта PDF

**Функция**: `exportReportPDF()` в `ReportsScreen.tsx`

**Функционал**:
- Загружает данные отчета через `/reports/export-pdf`
- Подготавливает данные для PDF генерации
- Показывает предпросмотр PDF

### 3. ✅ Добавлена функция сохранения PDF

**Функция**: `handleSavePDF()` в `ReportsScreen.tsx`

**Функционал**:
- Конвертирует blob в base64
- Сохраняет PDF через `/reports/save-pdf`
- Обновляет `pdf_url` в `user_reports`
- Показывает ссылку на PDF

### 4. ✅ Добавлена кнопка экспорта в UI

**Местоположение**: Рядом с кнопкой "Обновить AI-обзор"

**Функционал**:
- Показывается только для Premium пользователей
- Показывает "Экспорт PDF" если PDF нет
- Показывает "Скачать PDF" если PDF уже создан
- Отключается во время генерации

### 5. ✅ Добавлен предпросмотр PDF

**Компонент**: Использует `BlobProvider` из `@react-pdf/renderer`

**Функционал**:
- Показывает iframe с предпросмотром PDF
- Кнопка "Сохранить PDF" для финального сохранения
- Индикатор загрузки во время генерации

### 6. ✅ Обновлен loadLastSavedReport

**Изменения**:
- Теперь загружает `id` и `pdf_url` из `user_reports`
- Сохраняет `currentReportId` для сохранения PDF
- Показывает ссылку на PDF если уже существует
