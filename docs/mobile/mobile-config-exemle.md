# 📱 mobile-config.md
**Проект:** Unity / PactCRM / KIRA AI (универсальный шаблон)  
**Раздел:** Super Admin → Mobile  
**Цель:** централизованная настройка и управление базовыми параметрами мобильного приложения React Native без ручного обновления кода.

---

## 🎯 Цели и назначение

Раздел **Mobile Config** позволяет Super Admin:
- настраивать дизайн и контент мобильного приложения;
- управлять splash-экраном, онбордингом, авторизацией, темами, offline и push-настройками;
- обновлять мобильное приложение без App Store / Google Play публикации (через OTA-конфигурации);
- синхронизировать базовые UI/UX элементы между **web** и **mobile** версиями.

## 🌍 Мультиязычность (i18n Sync)

### 🎯 Цель
Обеспечить единое управление языками между Web и Mobile приложением, чтобы:
- пользователи видели одинаковые тексты, подсказки, кнопки, уведомления;
- переводы обновлялись централизованно через Super Admin → “Localization” или “Mobile”;
- мобильное приложение могло получать и применять актуальные переводы без перезапуска.

---

### ⚙️ Функциональные возможности

| Параметр | Описание |
|-----------|-----------|
| **Default Language** | Основной язык интерфейса по умолчанию (например, `ru`) |
| **Available Languages** | Список доступных языков (`["ru", "en", "ka"]`) |
| **Auto Detect** | Автоматическое определение языка устройства |
| **Dynamic Switch** | Возможность переключать язык из настроек профиля |
| **Shared Translation Source** | Тексты берутся из одной базы Supabase (например, таблица `translations`) |
| **Offline Support** | Кэширование переводов в AsyncStorage для офлайн-режима |

---

### 🗂️ Структура данных в Supabase

#### Таблица: `translations`
| Поле | Тип | Описание |
|------|------|-----------|
| `key` | text | Уникальный идентификатор текста (например, `onboarding_title_1`) |
| `ru` | text | Русский перевод |
| `en` | text | Английский перевод |
| `ka` | text | Грузинский перевод |
| `category` | text | Раздел (onboarding, auth, settings и т.д.) |
| `updated_at` | timestamp | Дата последнего обновления |

#### Пример записи:
```json
{
  "key": "onboarding_title_1",
  "ru": "Добро пожаловать в Unity",
  "en": "Welcome to Unity",
  "ka": "მოგესალმებით Unity-ში",
  "category": "onboarding"
}
```

---

### 📦 Пример конфигурации в `mobile_settings`

```json
{
  "languages": {
    "default": "ru",
    "available": ["ru", "en", "ka"],
    "autoDetect": true,
    "offlineCache": true,
    "lastSync": "2025-10-30T12:00:00Z"
  }
}
```

---

### 🔁 Логика синхронизации
1. Проверяется язык устройства
2. При `autoDetect` выбирается ближайший поддерживаемый язык
3. Запрашиваются переводы `/api/translations?lang=ru`
4. Кэшируются локально в AsyncStorage
5. При изменении версии переводов Supabase отправляет обновления OTA
6. Пользователь может сменить язык вручную в настройках

## 🧭 Сценарии взаимодействия (UX Flow)

### Сценарий 1: Настройка мобильного онбординга
Super Admin обновляет контент онбординга, приложение получает новые данные при запуске через `/mobile/settings`.

### Сценарий 2: OTA обновление темы и Splash
Admin меняет цвета и изображение, мобильное приложение при старте обновляет конфигурацию (silent update).

### Сценарий 3: Offline-сценарий
При потере соединения пользователь видит 🔴 “Offline Mode”, действия кэшируются и синхронизируются при восстановлении сети.

### Сценарий 4: Мультиязычность
Admin добавляет новые переводы в таблицу `translations`; мобильное приложение автоматически синхронизирует их и обновляет тексты.

---

## 🔒 Безопасность
- Только роль **SuperAdmin** имеет права редактирования.
- Все изменения логируются в `audit_logs`.
- При каждом изменении создаётся `version_id` для OTA трекинга.
- Клиент проверяет подпись токена перед применением новых настроек.
