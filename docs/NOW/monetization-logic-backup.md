## 💎 Модель монетизации

### Freemium модель

UNITY использует **freemium** бизнес-модель:
- **Free план** — базовый функционал с ограничениями
- **Premium план** — полный функционал за $4.99/месяц

**Цели:**
- Conversion rate: **15%** (Free → Premium)
- Churn rate: **< 5%** в месяц
- LTV (Lifetime Value): **$60** (средняя подписка 12 месяцев)

## 🔐 Как работает проверка Premium

### 1. При создании записи

**Файл:** `src/features/mobile/home/components/chat-input/messageHandlers.ts`

```javascript
  const entriesCount = await getEntriesCountThisMonth(userId);

    return;
  }

// Шаг 3: Создаём запись

```

### 2. При включении Offline режима

**Файл:** `src/shared/lib/offline/helpers.ts`

```javascript
function canUseOfflineMode(userData) {
  // Проверка 1: Пользователь залогинен?
  if (!userData) {
    return {
      allowed: false,
      reason: 'not_authenticated',
      message: 'Войдите в систему'
    };
  }

  // Проверка 2: Есть Premium?
  if (!userData.isPremium) {
    return {
      allowed: false,
      reason: 'premium_required',
      message: 'Offline режим доступен только для Premium'
    };
  }

  // Проверка 3: Включен ли offline в настройках?
  if (!userData.offlineEnabled) {
    return {
      allowed: false,
      reason: 'disabled',
      message: 'Включите Offline режим в настройках'
    };
  }

  return { allowed: true };
}
```

## 🔧 Техническая реализация (текущая)

### База данных

**Таблица profiles:**

```sql
CREATE TABLE profiles (
  id UUID PRIMARY KEY,
  email TEXT NOT NULL,
  name TEXT,
  role TEXT DEFAULT 'user',      -- 'user' | 'super_admin'
  is_premium BOOLEAN DEFAULT false,
  offline_enabled BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Индекс для быстрого поиска Premium пользователей
CREATE INDEX idx_profiles_is_premium ON profiles(is_premium);
```

**Таблица subscriptions (планируется):**

```sql
CREATE TABLE subscriptions (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  plan TEXT NOT NULL,
  status TEXT NOT NULL,
  start_date TIMESTAMP NOT NULL,
  end_date TIMESTAMP,
  stripe_subscription_id TEXT,
  stripe_customer_id TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);
```

```typescript
const isPremium = userData?.profile?.isPremium || userData?.isPremium || false;
```

**SQL запросы для статистики:**

```sql
-- Общая статистика
SELECT 
  COUNT(*) FILTER (WHERE is_premium = true) as premium_count,
  COUNT(*) FILTER (WHERE is_premium = false) as free_count,
  ROUND(
    COUNT(*) FILTER (WHERE is_premium = true) * 100.0 / COUNT(*),
    1
  ) as conversion_rate
FROM profiles;

-- Месячный доход (при цене $4.99)
SELECT 
  COUNT(*) * 4.99 as monthly_revenue
FROM subscriptions
WHERE status = 'active'
  AND plan = 'premium_monthly';

-- Churn rate (отток за месяц)
SELECT 
  COUNT(*) FILTER (WHERE status = 'cancelled' AND updated_at > NOW() - INTERVAL '30 days') * 100.0 /
  COUNT(*) FILTER (WHERE status = 'active') as churn_rate
FROM subscriptions;
```
