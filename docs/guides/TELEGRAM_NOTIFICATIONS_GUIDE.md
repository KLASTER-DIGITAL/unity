# 📱 Telegram Notifications - Руководство пользователя

**Версия**: 1.0  
**Дата**: 2025-11-11  
**Статус**: Production Ready

---

## 🎯 Что это?

Telegram уведомления позволяют получать все уведомления из UNITY-v2 прямо в Telegram через бота `@diary_bookai_bot`.

### Преимущества:
- ✅ **Надежность** - уведомления приходят даже если браузер закрыт
- ✅ **Кросс-платформенность** - работает на всех устройствах (iOS, Android, Desktop)
- ✅ **Автоматический fallback** - если Web Push недоступен, уведомление придет в Telegram
- ✅ **Мгновенная доставка** - уведомления приходят в реальном времени

---

## 🚀 Быстрый старт (для пользователей)

### Шаг 1: Найти бота
1. Откройте Telegram
2. Найдите бота: `@diary_bookai_bot`
3. Нажмите **Start** или отправьте `/start`

### Шаг 2: Связать аккаунт
После отправки `/start` бот ответит:

```
👋 Привет! Я бот UNITY Diary.

Для получения уведомлений, пожалуйста:
1. Откройте UNITY приложение
2. Перейдите в Настройки → Telegram
3. Нажмите "Связать Telegram"
4. Следуйте инструкциям

После связывания вы будете получать уведомления здесь!
```

### Шаг 3: Связать в приложении
1. Откройте UNITY приложение (https://unity-wine.vercel.app)
2. Войдите в свой аккаунт
3. Перейдите в **Настройки** → **Telegram**
4. Нажмите **"Связать Telegram"**
5. Авторизуйтесь через Telegram Login Widget
6. Готово! ✅

### Шаг 4: Проверить статус
Отправьте `/status` боту для проверки связывания:

```
✅ Ваш аккаунт связан!

Имя: Rustam Karimov
Email: rustam@leadshunter.biz
Telegram: @rustamkarimov

Вы будете получать уведомления в этом чате.
```

## 📋 Команды бота

### `/start`
Начать работу с ботом и получить инструкции по связыванию аккаунта.

**Пример**:
```
/start
```

**Ответ**:
```
👋 Привет! Я бот UNITY Diary.
[инструкции по связыванию]
```

---

### `/help`
Показать список доступных команд и справку.

**Пример**:
```
/help
```

**Ответ**:
```
📚 Доступные команды:

/start - Начать работу с ботом
/help - Показать эту справку
/status - Проверить статус связывания

Для получения уведомлений необходимо связать ваш Telegram с аккаунтом UNITY.
```

---

### `/status`
Проверить статус связывания аккаунта.

**Пример**:
```
/status
```

**Ответ (если связан)**:
```
✅ Ваш аккаунт связан!

Имя: Rustam Karimov
Email: rustam@leadshunter.biz
Telegram: @rustamkarimov
```

**Ответ (если НЕ связан)**:
```
❌ Ваш аккаунт не связан.

Для связывания:
1. Откройте UNITY приложение
2. Перейдите в Настройки → Telegram
3. Нажмите "Связать Telegram"
```

## 🔔 Типы уведомлений

Вы будете получать следующие уведомления в Telegram:

### 1. **Realtime уведомления** (мгновенные)
- ✅ **Новая запись создана** - когда вы создаете запись в дневнике
- 🏆 **Достижение разблокировано** - когда вы получаете новое достижение
- 🔥 **Streak Milestone** - когда достигаете нового рекорда серии (3, 7, 14, 30, 60, 90, 100, 180, 365 дней)

### 2. **Запланированные уведомления**
- 📅 **Ежедневное напоминание** - напоминание написать запись (настраивается в Settings)
- 💪 **Еженедельная мотивация** - мотивационное сообщение раз в неделю
- 🎯 **Напоминание о целях** - напоминание о ваших целях

### 3. **AI персонализированные** (Premium)
- 🤖 **AI рекомендации** - персональные рекомендации на основе ваших записей
- 📊 **AI инсайты** - анализ ваших эмоций и паттернов

## ⚙️ Настройки уведомлений

### Где настроить?
1. Откройте UNITY приложение
2. Перейдите в **Настройки** → **Уведомления**
3. Выберите типы уведомлений которые хотите получать

### Доступные настройки:
- ✅ **Включить/выключить** каждый тип уведомлений
- ⏰ **Время отправки** ежедневных напоминаний
- 📱 **Канал доставки** - Web Push, Telegram, или оба

## 🔧 Устранение неполадок

### Уведомления не приходят?

**1. Проверьте связывание**:
```
/status
```
Если аккаунт не связан → следуйте инструкциям выше.

**2. Проверьте настройки уведомлений**:
- Откройте UNITY → Настройки → Уведомления
- Убедитесь что нужные типы уведомлений включены

**3. Проверьте что бот не заблокирован**:
- Откройте чат с `@diary_bookai_bot`
- Убедитесь что вы не заблокировали бота

**4. Попробуйте переподключить**:
- Отправьте `/start` боту снова
- Перейдите в UNITY → Настройки → Telegram
- Нажмите "Отключить Telegram" → "Связать Telegram"

## 🔒 Безопасность и конфиденциальность

### Какие данные хранятся?
- `telegram_id` - ваш Telegram ID
- `telegram_username` - ваш Telegram username
- `telegram_chat_id` - ID чата для отправки уведомлений

### Как данные используются?
- **ТОЛЬКО** для отправки уведомлений
- **НЕ** передаются третьим лицам
- **НЕ** используются для рекламы

### Как отключить?
1. Откройте UNITY → Настройки → Telegram
2. Нажмите **"Отключить Telegram"**
3. Ваши данные будут удалены из системы
