## 🔗 Полезные команды

### EAS Builds
```bash
# Проверить статус build'ов
eas build:list --limit 5

# Запустить iOS Simulator build
eas build:run -p ios --latest

# Запустить Android build
eas build:run -p android --latest

# Опубликовать EAS Update
eas update --channel development --message "Update message"
```

### Expo Dev Server
```bash

# Сканировать QR код в Expo Go
```

## 🎓 Lessons Learned

1. **Expo Go не поддерживает EAS Update** - нужны development builds
2. **Hermes требует polyfill для import.meta** - добавлен в babel.config.js
3. **FFmpeg не работает в React Native** - создан platform-specific mock
4. **Gradle deprecated API** - требует обновления конфигурации
5. **Platform adapters критичны** - для успешной миграции на React Native
