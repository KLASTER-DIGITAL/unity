## ❌ Проблемы которые нашли

### Проблема 1: Некоторые тексты не переводятся (КРИТИЧНО)

**Что это значит**:
Когда пользователь выбирает казахский язык, некоторые тексты остаются на русском.

**Где проблема**:
- "Лента последних записей" → должно быть "Соңғы жазбалар лентасы"
- "Смотреть все" → должно быть "Барлығын көру"
- "Нет текста" → должно быть "Мәтін жоқ"

**Почему это произошло**:
Программист забыл использовать систему переводов и написал текст напрямую в коде.

**Как исправить**:
Заменить hardcoded тексты на вызовы функции перевода `t()`.

**Время на исправление**: 15 минут

---

### Проблема 2: "Мусор" в базе данных (КРИТИЧНО)

**Что это значит**:
В базе данных есть ~50 "мусорных" ключей которые не должны там быть.

**Примеры мусора**:
- Пути к файлам: `../shadcn-io/3d-card`, `@/components/preloader/Black-2.json`
- Символы: ` ` (пробел), `-` (дефис), `:` (двоеточие)
- Технические слова: `link`, `meta`, `script`, `ETag`

**Почему это произошло**:
Скрипт автоматического сканирования кода ошибочно добавил эти ключи.

**Как исправить**:
Выполнить SQL скрипт для удаления мусорных ключей.

**Время на исправление**: 5 минут

---

### Проблема 3: Некоторые компоненты не готовы к React Native (ВАЖНО)

**Что это значит**:
Когда мы будем мигрировать на React Native (мобильное приложение), некоторые компоненты нужно будет переписать.

**Какие компоненты**:
- `AchievementHeader.tsx` - заголовок с аватаром
- `ChatInputSection.tsx` - поле ввода текста
- `MotivationCardsSection.tsx` - карточки мотивации

**Как исправить**:
Создать `.native.tsx` версии этих компонентов.

**Время на исправление**: 4-6 часов

## 🎓 Как избежать проблем в будущем

### Правило 1: Всегда использовать систему переводов
```typescript
// ❌ НЕПРАВИЛЬНО
<h2>Лента последних записей</h2>

// ✅ ПРАВИЛЬНО
const { t } = useTranslation();
<h2>{t('home.recent_entries', 'Лента последних записей')}</h2>
```
