# Инструкция: Автоперевод для грузинского языка

**Дата**: 2025-11-21  
**Язык**: Грузинский (ka, ქართული, 🇬🇪)  
**Статус**: Готово к выполнению

---

## 📋 Инструкция

### Способ 1: Через админ-панель (Рекомендуется)

1. **Войти в админ-панель**:
   - Открыть https://unity-wine.vercel.app/?view=admin
   - Войти как super_admin: `diary@leadshunter.biz` / `admin123`

2. **Перейти в раздел переводов**:
   - Нажать на вкладку "Настройки" в левом меню
   - Выбрать подвкладку "Переводы" или "Языки"

3. **Запустить автоперевод**:
   - Найти грузинский язык (🇬🇪 ქართული)
   - Нажать на язык → откроется детальная страница
   - Найти вкладку "Автоперевод AI"
   - Выбрать:
     - **Источник**: `ru` (Русский)
     - **Цель**: `ka` (Грузинский)
   - Нажать кнопку "Запустить автоперевод"

4. **Дождаться завершения**:
   - Процесс может занять 5-10 минут (зависит от количества ключей)
   - Появится уведомление об успешном завершении
   - Показана стоимость перевода

---

### Способ 2: Через Edge Function напрямую (Для разработчиков)

Если нужно запустить автоперевод программно:

```typescript
const response = await fetch(
  `${VITE_SUPABASE_URL}/functions/v1/auto-translate`,
  {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${session.access_token}`,
    },
    body: JSON.stringify({
      sourceLanguage: 'ru',
      targetLanguages: ['ka'],
    }),
  }
);
```

## 📊 Текущая статистика

- **Русский язык (ru)**: 664 ключа
- **Грузинский язык (ka)**: 585 ключей
- **Отсутствует в грузинском**: ~79 ключей

**Примечание**: Количество может отличаться из-за технических ключей и мусорных записей в БД.

## ✅ Проверка результата

После завершения автоперевода:

1. **Проверить статистику**:
   - В админ-панели → Языки → Грузинский
   - Проверить прогресс перевода (должен быть близок к 100%)

2. **Проверить качество**:
   - Открыть несколько ключей вручную
   - Убедиться что переводы корректны
   - Проверить что нет технических ключей

3. **Протестировать в приложении**:
   - Создать тестовый аккаунт с языком `ka`
   - Пройти онбординг на грузинском
   - Проверить основные экраны

---

## 🐛 Известные проблемы

1. **Технические ключи**: В БД могут быть технические ключи (пути к файлам, символы), которые не нужно переводить
2. **Мусорные записи**: Некоторые записи могут быть дубликатами или ошибками
3. **Время выполнения**: Автоперевод может занять время из-за большого количества ключей

## 💰 Стоимость

Автоперевод использует GPT-4o-mini:
- **Модель**: gpt-4o-mini
- **Стоимость**: ~$0.00015 за 1K токенов промпта + $0.0006 за 1K токенов ответа
- **Оценка**: ~$0.10-0.50 за 79 ключей (зависит от длины текстов)
