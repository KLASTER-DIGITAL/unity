# 🌐 I18n smoke-check (ru/en/ka/kk)
Версия: 2025-11-22  
Цель: быстрая проверка ключевых языков UI/PDF без полного регресса.

## Что проверяем
- Формат дат в отчётах и PDF-просмотре (месяц + год, неделя).
- Наличие ключевых строк: заголовки отчёта, кнопки «Создать отчёт/книгу», заголовки PDF.
- Отсутствие пропавших ключей/`[object Object]`.

## Мини-план (ручной или автоскрипт)
1) Выставить язык профиля/окружения: ru → en → ka → kk.  
2) Открыть экран отчётов/книг:  
   - Заголовок «Отчёты»/`Reports`/`ანგარიშები`/`Есептер`.  
   - Подзаголовок, кнопки «Открыть отчёты», «Создать отчёт», «Создать новую книгу».  
3) Проверить блок настроения: подписи позитив/нейтраль/негатив на выбранном языке.  
4) PDF-просмотр: заголовок, статистика, подписи mood/entries/achievements локализованы.  
5) Проверить дату периода: месяц + год отображаются корректно для языка (особенно ka/kk).
