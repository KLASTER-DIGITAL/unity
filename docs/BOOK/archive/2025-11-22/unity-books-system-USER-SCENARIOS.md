# 👤 2. Персоны пользователей (Personas)

## Persona A: «Личный дневник»
- Пользователь пишет для себя.
- 10–20 записей в месяц.
- Важны поддержка, осознанность, духовность.
- Начинает с FREE, затем хочет глубокую историю.

## Persona B: «Семейный пользователь»
- Пишет о детях, жене/муже, путешествиях.
- Для него важны книги для детей и семьи.
- PREMIUM обязателен для семейных глав.

## Persona C: «Профессиональный пользователь»
- Записывает цели, работу, проекты.
- Интересуют выводы, прогресс, рост.

## Persona D: «Минималист»
- Пишет мало.
- Хочет простые книги.

# 📕 3. Основные сценарии (High-Level Scenarios)

### Сценарий 1. Пользователь создаёт FREE книгу
1. Открывает «Книги».
2. Нажимает «Создать книгу».
3. Выбирает период.
4. Кликает «Создать (FREE)».
5. Через 2–5 секунд появляется PDF.
6. Открывает, листает.
7. Скачивает.

### Сценарий 2. Пользователь создаёт PREMIUM книгу
1. Нажимает «Создать AI-книгу».
2. Проходит Wizard: период → тип книги → стиль → подтверждение.
3. Экран ожидания.
4. AI создаёт структуру.
5. Пользователь видит черновик.
6. Сохраняет как PDF.
7. Или редактирует → получает v2.

### Сценарий 3. Пользователь переходит FREE → PREMIUM
1. Пользователь открывает FREE книгу.
2. Видит кнопку: «Создать AI-версию этой книги».
3. Переходит на Premium Paywall.
4. Оплачивает.
5. Нажимает «Создать Premium-книгу».
6. Получает AI-книгу за тот же период.

# 📖 4. Сценарии использования FREE и PREMIUM

## FREE

### Use Case F-1: Создание простой книги
- Trigger: пользователь нажимает «Создать книгу».
- System:
  - собирает список записей,
  - формирует краткие тексты,
  - создаёт HTML,
  - рендерит PDF,
  - сохраняет book record.

### Use Case F-2: Просмотр книги
- Trigger: пользователь нажимает на книгу в библиотеке.
- System: открывает PDF viewer.

### Use Case F-3: Скачивание PDF
- Trigger: «Скачать».
- System: скачивает файл.

### Use Case F-4: Попытка открыть Premium-функцию
- Trigger: пользователь нажимает «AI-главы» или «Семейные главы».
- System: показывает paywall.

---

## PREMIUM

### Use Case P-1: Создание AI-книги
- Trigger: пользователь Premium нажимает «Создать AI-книгу».
- System:
  1. Собирает entry_summaries.
  2. Загружает snapshot.
  3. Вызывает AI для структуры.
  4. Вызывает AI для глав.
  5. Вызывает AI для цитат.
  6. Создаёт черновик (story_json).
  7. Передаёт в PDF рендер.

### Use Case P-2: Редактирование AI-книги
- Trigger: «Редактировать книгу».
- User:
  - редактирует главы,
  - добавляет фото,
  - удаляет текст,
  - меняет стиль.
- System:
  - генерирует v2,
  - создаёт новый PDF.

### Use Case P-3: Авто-книга месяца
- Trigger: Cron (1-е число каждого месяца).
- Условия:
  - есть Premium,
  - есть >5 записей,
  - нет уже созданной книги.
- System:
  - создаёт черновик,
  - рендерит PDF,
  - отправляет пуш: «Ваша книга месяца готова».

### Use Case P-4: Создание семейной книги
- Trigger: пользователь выбирает «Семейная книга».
- System:
  - собирает записи с person_tags: [Карина, Арина, семья],
  - создаёт главы по персонам.

# 🌍 5. Сценарии мультиязычности

### Scenario L-1: Создание книги на языке профиля
1. В профиле стоит язык RU.
2. Пользователь создаёт книгу.
3. Все UI подписи, вступление, главы — на русском.
4. AI пишет на русском.

### Scenario L-2: Смена языка профиля
1. Пользователь изменяет язык на English.
2. Созданные ранее книги остаются на RU.
3. Новые книги создаются на EN.

### Scenario L-3: FREE-книга на новом языке
FREE книга генерируется:
- структура — на новом языке,
- записи — оригинальные.

# 🧠 6. AI сценарии

### Scenario AI-1: AI выбирает структуру книги
AI создаёт каркас:
- Вступление
- Семья
- Внутренний мир
- Работа
- Достижения
- Эмоции
- Итог

### Scenario AI-2: AI выбирает цитаты
1. Берёт excerpts из entry_summaries.
2. Выбирает 3–10 ключевых цитат.
3. Вставляет их в книгу.

### Scenario AI-3: AI выбирает фото
На основе source_entry_ids:
- важно ли фото,
- подходит ли к главе.

### Scenario AI-4: AI ошибки
Если AI не дал текст:
- создаём fallback текст:
  - «Этот месяц был важным периодом…».

# 📷 7. Сценарии работы с фото

### Scenario PH-1: Фото в FREE книге
- создаётся коллаж (3×3 или 4×4),
- без логики по смыслу.

### Scenario PH-2: Фото в PREMIUM книге
- AI распределяет фото по главам,
- добавляет подписи,
- пользователь может:
  - удалить фото,
  - добавить новое,
  - изменить порядок.

### Scenario PH-3: Ошибка загрузки фото
- показываем сообщение: «Не удалось загрузить фото».

# 📄 8. Сценарии PDF рендера

### Scenario PDF-1: Успешный рендер
1. HTML → Puppeteer.
2. PDF сохраняется в Storage.
3. Пользователь получает уведомление.

### Scenario PDF-2: Упавший рендер
Причины:
- нет шрифтов,
- слишком длинный HTML,
- ошибка Puppeteer.

Фоллбек:
- перегенерация,
- логирование,
- сообщение пользователю.

# 🚨 9. Сценарии ошибок

### Error E-1: Нет сети
- FREE:
  - просмотр книг доступен,
  - создать нельзя.
- PREMIUM:
  - AI недоступен,
  - Editor блокируется.

### Error E-2: AI не отвечает
- fallback текст,
- предложение попробовать позже.

### Error E-3: Supabase Storage недоступен
- книга сохраняется как “draft without pdf”.

# 🔁 11. Сценарии версионирования

# 🧩 12. End-to-End сценарий (полный путь)

### Полный путь пользователя Premium:

1. Пользователь пишет 30 записей в октябре.
2. 1 ноября → получает уведомление:
   - «Ваша книга октября готова!»
3. Заходит → видит AI-книгу.
4. Читает главы:
   - Семья,
   - Карина,
   - Работа,
   - Внутренний мир.
5. Меняет фото в 2 главах.
6. Создаёт v2.
7. Скачивает PDF.
8. Делится с женой.
9. Через 3 месяца → создаёт квартальную книгу.
