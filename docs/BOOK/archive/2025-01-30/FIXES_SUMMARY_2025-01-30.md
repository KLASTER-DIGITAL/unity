# 📋 Сводка исправлений системы книг - 30 января 2025

## Исправленные проблемы

### ✅ 1. Убрана кнопка "Создать PDF" из редактора
**Проблема**: Кнопка "Создать PDF" отображалась в редакторе, хотя PDF должен генерироваться автоматически.

**Решение**: 
- Удалена кнопка "Создать PDF" из редактора
- PDF теперь генерируется автоматически при сохранении книги

**Файлы**: `src/features/mobile/reports/components/BookDraftEditor.tsx`

### ✅ 2. Добавлена автоматическая генерация PDF при сохранении
**Проблема**: PDF не генерировался автоматически после сохранения книги.

**Решение**:
- После успешного сохранения книги автоматически запускается генерация PDF (если PDF еще не создан)
- Генерация происходит в фоне, не блокируя UI
- Пользователь видит toast уведомление об успешном сохранении

**Файлы**: `src/features/mobile/reports/components/BookDraftEditor.tsx`

### ✅ 3. Исправлено toast уведомление об успешном сохранении
**Проблема**: После сохранения не было понятного уведомления об успехе.

**Решение**:
- Добавлено toast уведомление "Книга сохранена и готова!" для черновиков, которые стали готовыми
- Добавлено toast уведомление "Изменения сохранены" для обновления существующих книг

**Файлы**: `src/features/mobile/reports/components/BookDraftEditor.tsx`

### ✅ 4. Исправлен API endpoint в библиотеке книг
**Проблема**: В `BooksLibraryScreen` использовался старый API `BOOKS_RENDER_PUPPETEER` вместо нового `BOOKS_RENDER_VERCEL`.

**Решение**:
- Заменен `BOOKS_RENDER_PUPPETEER` на `BOOKS_RENDER_VERCEL` в функции `handleCreatePDF`
- Обновлен формат запроса (добавлен `accessToken` вместо `Authorization` header)

**Файлы**: `src/features/mobile/reports/components/BooksLibraryScreen.tsx`

### ✅ 5. Исправлена кодировка PDF для русского языка
**Проблема**: PDF на русском языке отображался с неправильной кодировкой (странные символы вместо кириллицы).

**Решение**:
- Улучшена загрузка шрифтов Noto Sans/Serif для русского языка
- Добавлен `display=block` для гарантии загрузки шрифтов перед рендерингом
- Добавлено `waitForFonts: true` в опции PDF генерации
- Улучшено ожидание загрузки шрифтов (проверка `document.fonts.check`)
- Добавлен `unicode-bidi: embed` для правильного отображения Unicode
- Приоритет шрифтов Noto Sans/Serif для русского языка

**Файлы**: `api/books/render-pdf.ts`
