# ✅ Release/Health Checklist — Книги и Отчёты (PWA/Web)
Версия: 2025-11-22  
Применение: выполнять перед релизом и перед крупными миграциями  
Связанный мастер: `docs/BOOK/BOOKS_SYSTEM_MASTER.md`

## 1. Конфигурация и окружение
- [ ] Env-файлы заполнены: Supabase URL/anon/service, Edge base URL, API_URLS.REPORTS, SENTRY/LOG.
- [ ] Флаги Premium/AI соответствуют конфигу окружения.
- [ ] Порты/хосты не захардкожены в UI (используется конфиг).

## 2. База данных и миграции
- [ ] Миграции применены в Supabase/PG, схемы совпадают с master-документом (таблицы profiles, entries, user_reports, drafts).
- [ ] Индексы/политики RLS проверены для книг/отчётов.

## 3. Edge Functions / API
- [ ] `/functions/v1/reports/generate` отвечает 200/OK, генерация AI успешна для тестового пользователя.
- [ ] `/reports/export-pdf` и `/reports/save-pdf` отвечают 200/OK.
- [ ] Логи Edge без ошибок за последние 24 ч.

## 4. Клиент (PWA/Web)
- [ ] Кэш/Service Worker не ломает обновления (проверен hard reload).
- [ ] Offline-guard: UX корректно сообщает об отсутствии сети.
- [ ] PDF предпросмотр/сохранение работает в последней сборке.
- [ ] Библиотека книг/мастер создания книги открываются и сохраняют черновик.

## 5. I18n
- [ ] Smoke-прогон ru/en/ka/kk: корректные даты, ключевые строки присутствуют.
- [ ] Нет выпадений ключей в UI и PDF.

## 6. Тесты
- [ ] UI smoke/integ тесты (отчёты, книги, PDF) зелёные.
- [ ] Snapshot PDF тест зелёный.
- [ ] Линтер/типизация пройдены.

## 7. Мониторинг и алерты
- [ ] Ошибки Sentry/логов без новых критов по книге/отчётам.
- [ ] Метрики генерации отчётов (успех/ошибка) в норме.

## 8. Документация
- [ ] Обновлены статусы в `CURRENT_STATUS_AND_NEXT_SPRINTS.md`.
- [ ] Изменения отражены в `BOOKS_SYSTEM_MASTER.md` (при необходимости).
- [ ] Устаревшие отчёты перенесены в `docs/BOOK/archive/`.
