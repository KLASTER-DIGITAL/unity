## ❌ Критическая проблема

### Edge Function `books-render-puppeteer` не работает

**Ошибка**:
```
[ERROR] [DRAFT-EDITOR] PDF creation failed: 500 Ошибка создания PDF: Deno.lstatSync is blocklisted on the current context
```

**Причина**:
- Библиотека Puppeteer для Deno использует `lstatSync` для работы с файловой системой
- Deno Deploy блокирует использование `lstatSync` в Edge Functions
- Это ограничение безопасности Deno Deploy

**Последствия**:
- ❌ Невозможно создать PDF файл через Edge Function
- ❌ Просмотр PDF не работает (файл не существует)
- ❌ Скачивание PDF не работает (файл не существует)

**Попытки исправления**:
- ✅ Добавлены дополнительные аргументы для Puppeteer (`--disable-gpu`, `--disable-software-rasterizer`)
- ⚠️ Проблема не решена - это ограничение Deno Deploy

## 🔧 Рекомендации по исправлению

### Вариант 1: Использовать альтернативную библиотеку для генерации PDF

**Проблема**: Puppeteer несовместим с Deno Deploy из-за использования `lstatSync`.

**Решение**: Использовать библиотеку, которая не требует файловой системы:
- `@react-pdf/renderer` - клиентская генерация PDF (уже используется в проекте)
- `pdfkit` - серверная генерация PDF без файловой системы
- `jsPDF` - клиентская генерация PDF

**Рекомендация**: Вернуться к клиентской генерации PDF через `@react-pdf/renderer`, так как:
- ✅ Уже интегрирован в проект
- ✅ Не требует файловой системы
- ✅ Работает в браузере
- ✅ Не имеет ограничений Deno Deploy

### Вариант 2: Использовать внешний сервис для генерации PDF

**Решение**: Использовать внешний сервис для генерации PDF:
- **PDFShift** - API для генерации PDF из HTML
- **Browserless** - Headless браузер как сервис
- **Puppeteer в отдельном сервисе** - Запустить Puppeteer на отдельном сервере (не Deno Deploy)

**Рекомендация**: Использовать PDFShift или Browserless, так как:
- ✅ Не требует настройки инфраструктуры
- ✅ Работает надежно
- ✅ Поддерживает Unicode и сложные стили
- ⚠️ Требует дополнительных затрат (платный сервис)

### Вариант 3: Исправить Edge Function для работы без файловой системы

**Проблема**: Puppeteer пытается использовать файловую систему для кэширования браузера.

**Решение**: Настроить Puppeteer так, чтобы он не использовал файловую систему:
- Использовать `userDataDir: undefined` или `userDataDir: null`
- Использовать `executablePath` для указания пути к браузеру (если доступен)
- Использовать `headless: true` и `ignoreHTTPSErrors: true`

**Статус**: ⚠️ Попытка исправления не увенчалась успехом - проблема в самой библиотеке Puppeteer для Deno.
