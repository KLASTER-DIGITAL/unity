# 🚨 КРИТИЧЕСКАЯ ПРОБЛЕМА: Puppeteer не работает в Deno Deploy

**Дата**: 2025-01-30  
**Статус**: ❌ БЛОКИРУЕТ СОЗДАНИЕ PDF  
**Приоритет**: P0 (КРИТИЧНО)

---

## 🔴 Проблема

Edge Function `books-render-puppeteer` не работает из-за ошибки:

```
Deno.lstatSync is blocklisted on the current context
```

**Причина**: Puppeteer использует `lstatSync` для доступа к файловой системе, что запрещено в Deno Deploy.

**Влияние**:
- ❌ Невозможно создать PDF файл
- ❌ Просмотр PDF не работает (файл не существует)
- ❌ Скачивание PDF не работает (файл не существует)
- ❌ Вся функциональность книг блокирована

---

**Попытки исправления**:
- ✅ Добавлены аргументы `--disable-gpu`, `--disable-software-rasterizer`
- ✅ Установлены `headless: true`, `ignoreHTTPSErrors: true`
- ❌ Проблема не решена - это фундаментальное ограничение Deno Deploy

---

## 💡 Решения

### Вариант 1: Вернуться к клиентской генерации PDF (БЫСТРОЕ РЕШЕНИЕ)

**Использовать**: `@react-pdf/renderer` (уже был в проекте)

**Преимущества**:
- ✅ Работает немедленно
- ✅ Не требует серверной части
- ✅ Нет ограничений Deno Deploy
- ✅ Уже интегрирован в проект

**Недостатки**:
- ⚠️ Проблемы с Unicode (русский, грузинский)
- ⚠️ Нестабильность при длинных книгах
- ⚠️ Нагрузка на браузер

**Время реализации**: 2-4 часа

### Вариант 2: Использовать внешний сервис для генерации PDF

**Варианты**:
- **PDFShift** - API для генерации PDF из HTML ($0.01 за PDF)
- **Browserless** - Headless браузер как сервис ($0.05 за PDF)
- **Puppeteer в отдельном сервисе** - Запустить Puppeteer на отдельном сервере (не Deno Deploy)

**Преимущества**:
- ✅ Полная поддержка Unicode
- ✅ Стабильность
- ✅ Не зависит от Deno Deploy

**Недостатки**:
- ⚠️ Дополнительные затраты
- ⚠️ Требуется интеграция внешнего сервиса
- ⚠️ Зависимость от стороннего сервиса

**Время реализации**: 1-2 дня

### Вариант 3: Использовать другую библиотеку для серверной генерации PDF

**Варианты**:
- **pdfkit** - Серверная генерация PDF без файловой системы
- **jsPDF** - Клиентская генерация PDF (но можно использовать на сервере)
- **pdfmake** - Серверная генерация PDF

**Преимущества**:
- ✅ Работает в Deno Deploy
- ✅ Не требует файловой системы

**Недостатки**:
- ⚠️ Может быть сложнее с форматированием
- ⚠️ Может потребоваться переписать HTML генерацию

**Время реализации**: 2-3 дня
