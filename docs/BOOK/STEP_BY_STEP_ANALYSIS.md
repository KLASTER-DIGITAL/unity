## 📝 Шаг 1: Инициация создания книги

### ✅ Что реализовано:
- Кнопка "Создать книгу" в `BooksLibraryScreen`
- Открытие `BookCreationWizard`
- Определение тарифа пользователя (FREE/PREMIUM)

### ❌ Что не учтено:

1. **Нет проверки доступности функции**
   - Не проверяется, доступна ли функция для пользователя
   - Нет обработки случая, когда функция временно недоступна

2. **Нет аналитики инициирования**
   - Не отслеживается, сколько раз пользователь нажимает "Создать книгу"
   - Нет метрик отказов на первом шаге

3. **Нет onboarding для новых пользователей**
   - Первый раз создание книги не объясняется
   - Нет туториала или подсказок

## 📝 Шаг 2: Визард создания (5 шагов)

### ✅ Что реализовано:
- Шаг 0: Выбор тарифа (Step0PlanType)
- Шаг 1: Выбор периода (Step1Period с Shadcn Calendar)
- Шаг 2: Выбор категорий (Step2Contexts)
- Шаг 3: Выбор стиля (Step3Style)
- Шаг 4: Выбор макета (Step4Layout)
- Навигация между шагами
- Валидация на каждом шаге

### ❌ Что не учтено:

#### Шаг 0 (Выбор тарифа):
1. **Нет A/B тестирования**
   - Не тестируется, какой текст лучше конвертирует FREE → PREMIUM
   - Нет вариантов копирайтинга

2. **Нет предпросмотра различий**
   - Пользователь не видит, что получит в PREMIUM
   - Нет сравнения FREE vs PREMIUM

#### Шаг 1 (Период):
1. **Нет умных предложений периода**
   - Не предлагается "Последний месяц", "Последний квартал"
   - Нет быстрых кнопок для популярных периодов

2. **Нет предупреждения о малом количестве записей**
   - Пользователь может выбрать период с 0 записей
   - Валидация только при нажатии "Создать"

3. **Нет визуализации периода**
   - Не показывается календарь с отметками дней с записями
   - Нет графика активности за период

#### Шаг 2 (Категории):
1. **Нет группировки категорий**
   - Все категории в одном списке
   - Нет группировки по типам (семья, работа, здоровье)

2. **Нет поиска категорий**
   - Если категорий много, сложно найти нужную
   - Нет фильтрации

3. **Нет предпросмотра количества записей**
   - Не показывается, сколько записей в каждой категории
   - Пользователь не знает, что получит

#### Шаг 3 (Стиль):
1. **Нет детального описания стилей**
   - Описания слишком краткие
   - Нет примеров текста в каждом стиле

2. **Нет предпросмотра стиля**
   - Пользователь не видит, как будет выглядеть книга
   - Нет примеров PDF в каждом стиле

3. **Нет рекомендаций**
   - AI не рекомендует стиль на основе записей
   - Нет "Этот стиль подходит для ваших записей"

#### Шаг 4 (Макет):
1. **Нет визуального превью макета**
   - Превью слишком схематичное
   - Нет реальных примеров страниц

2. **Нет информации о влиянии макета**
   - Не объясняется, как макет влияет на PDF
   - Нет рекомендаций по выбору

## 📝 Шаг 3: Генерация черновика

### ✅ Что реализовано:
- Валидация минимума записей (5)
- Проверка лимита FREE (1 книга в месяц)
- Выбор правильного endpoint (FREE/PREMIUM/QUARTER/YEAR)
- API вызовы к Edge Functions
- Обработка ошибок
- Кэширование черновиков (content hash)

### ❌ Что не учтено:

1. **Нет оценки времени генерации**
   - Пользователь не знает, сколько ждать
   - Нет прогресс-бара с реальным временем

2. **Нет отмены генерации**
   - Если пользователь передумал, нельзя отменить
   - Генерация продолжается в фоне

3. **Нет уведомлений**
   - Если генерация долгая, нет push-уведомления о готовности
   - Пользователь должен ждать на экране

4. **Нет retry с измененными параметрами**
   - При ошибке можно только повторить с теми же параметрами
   - Нет возможности изменить параметры и повторить

5. **Нет детальной информации об ошибках**
   - Ошибки слишком общие
   - Пользователь не понимает, что делать

6. **Нет оптимизации для больших периодов**
   - Генерация книги за год может быть очень долгой
   - Нет предупреждения о длительности

---

## 📝 Шаг 4: AI-генерация контента

### ✅ Что реализовано:
- Использование entry_summaries (не raw entries)
- Загрузка snapshot (если есть)
- Вызов OpenAI GPT-4o-mini
- Динамический выбор AI-операции по стилю
- Генерация структуры книги
- Генерация оглавления
- Генерация итогов месяца (PREMIUM)
- Добавление хроники

### ❌ Что не учтено:

1. **Нет использования Snapshot Layer**
   - Edge Function `snapshots-generate-monthly` существует, но не используется
   - AI не получает агрегированные данные периода

2. **Нет Context Engine**
   - Не извлекаются персоны (persons) из записей
   - Не группируются главы по людям ("Карина", "Арина")
   - Контексты = просто теги (categories)

3. **Нет валидации качества AI-текста**
   - Не проверяется, что AI не использовал запрещенные фразы
   - Нет проверки на шаблонность текста

4. **Нет fallback при ошибке AI**
   - Если AI вернул ошибку, нет запасного варианта
   - Пользователь получает ошибку без альтернативы

5. **Нет оптимизации промптов**
   - Промпты могут быть слишком длинными для больших периодов
   - Нет динамической обрезки контекста

6. **Нет A/B тестирования промптов**
   - Не тестируется, какие промпты дают лучший результат
   - Нет вариантов системных промптов

## 📝 Шаг 5: Отображение прогресса

### ✅ Что реализовано:
- Компонент `BookGenerationProgress`
- Анимация прогресса
- Обработка ошибок
- Кнопка "Повторить"

### ❌ Что не учтено:

1. **Нет реального прогресса**
   - Прогресс-бар не отражает реальное состояние
   - Нет WebSocket для обновления прогресса

2. **Нет детальной информации о процессе**
   - Пользователь не видит, что происходит ("Загрузка записей...", "Генерация AI...")
   - Нет пошагового прогресса

3. **Нет возможности закрыть и вернуться позже**
   - Если генерация долгая, пользователь должен ждать
   - Нет "Продолжить позже"

## 📝 Шаг 6: Модалка успеха

### ✅ Что реализовано:
- Компонент `BookCreationSuccessModal`
- Конфетти анимация
- Кнопки действий

### ❌ Что не учтено:

   - Не показывается, сколько времени заняло
   - Нет информации о количестве страниц

2. **Нет рекомендаций следующих шагов**
   - Не предлагается "Редактировать книгу" или "Создать еще одну"

## 📝 Шаг 7: Редактор черновика

### ✅ Что реализовано:
- Компонент `BookDraftEditor`
- Редактирование текста (title, prologue, chapters, epilogue)
- Загрузка фото
- Предпросмотр PDF

### ❌ Что не учтено:

1. **Нет визуального редактора (WYSIWYG)**
   - Редактирование только через текстовые поля
   - Нет форматирования текста (жирный, курсив, списки)

2. **Нет drag-and-drop для фото**
   - Фото загружаются, но не перетаскиваются
   - Нет изменения порядка фото

3. **Нет изменения структуры глав**
   - Нельзя переместить главу
   - Нельзя удалить главу
   - Нельзя добавить новую главу

4. **Нет редактирования оглавления**
   - Оглавление генерируется автоматически
   - Нельзя изменить вручную

5. **Нет сравнения версий**
   - При редактировании не видно, что изменилось
   - Нет diff между версиями

6. **Нет автосохранения**
   - Изменения не сохраняются автоматически
   - Риск потери данных при закрытии

7. **Нет отмены изменений (Undo/Redo)**
   - Нет истории изменений
   - Нельзя отменить случайное изменение

## 📝 Шаг 8: Генерация PDF

### ✅ Что реализовано:
- Компонент `BookPDFDocument` (React-PDF)
- Регистрация шрифтов (Noto Sans, Noto Serif)
- Рендеринг всех элементов (обложка, оглавление, главы, итоги)
- Загрузка в Supabase Storage
- Обновление статуса книги

### ❌ Что не учтено:

1. **Нет серверного рендеринга**
   - PDF генерируется на клиенте
   - Нагрузка на устройство пользователя
   - Проблемы с шрифтами (CORS)

2. **Нет оптимизации размера PDF**
   - PDF может быть очень большим
   - Нет сжатия изображений
   - Нет оптимизации шрифтов

3. **Нет предпросмотра перед генерацией**
   - Пользователь не видит, как будет выглядеть PDF
   - Нет оценки размера файла

4. **Нет прогресса генерации PDF**
   - Пользователь не видит, сколько осталось
   - Нет информации о процессе

5. **Нет обработки ошибок генерации**
   - Если PDF не сгенерировался, нет детальной ошибки
   - Нет fallback варианта

6. **Нет кэширования PDF**
   - PDF генерируется каждый раз заново
   - Нет сохранения в IndexedDB для offline

---

## 📝 Шаг 9: Хранение и версионирование

### ✅ Что реализовано:
- Сохранение в `books_archive`
- Сохранение PDF в Supabase Storage
- Поле `version` для версионирования
- Удаление старых версий при перезаписи

### ❌ Что не учтено:

1. **Нет истории версий в UI**
   - Версии хранятся в БД, но не отображаются
   - Пользователь не видит все версии книги

2. **Нет сравнения версий**
   - Нет diff между версиями
   - Нельзя увидеть, что изменилось

3. **Нет восстановления версии**
   - Нельзя вернуться к старой версии
   - Нет "Откатить изменения"

4. **Нет метаданных версий**
   - Не сохраняется, кто и когда создал версию
   - Нет комментариев к версиям

5. **Нет ограничения количества версий**
   - Может накопиться много версий
   - Нет автоматической очистки старых версий

## 📝 Шаг 10: Просмотр и скачивание

### ✅ Что реализовано:
- Просмотр PDF в `PDFViewer`
- Скачивание PDF
- Web Share API для мобильных

### ❌ Что не учтено:

1. **Нет offline просмотра**
   - PDF не кэшируется локально
   - Нельзя открыть без интернета

2. **Нет экспорта в другие форматы**
   - Только PDF
   - Нет EPUB, DOCX, HTML

3. **Нет шаринга через социальные сети**
   - Только Web Share API
   - Нет прямых кнопок для Telegram, WhatsApp

4. **Нет печати**
   - Нет оптимизации для печати
   - Нет специального режима печати

5. **Нет полноэкранного просмотра**
   - PDF открывается в iframe
   - Нет полноэкранного режима
