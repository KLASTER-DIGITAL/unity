## 📊 Критические проблемы (выявлены)

### Проблема 1: НЕТ разделения FREE vs PREMIUM ❌

**Детали**:
- Все книги создаются через AI (дорого)
- Нет FREE-версии без AI
- Низкая конверсия в Premium
- Высокая стоимость для пользователей

**Влияние**:
- 💰 Затраты на токены: $X на пользователя в месяц
- 📉 Конверсия FREE → PREMIUM: N/A (нет FREE)
- ⏱️ Время генерации: 40-60 сек (медленно)

**Решение** (в Backlog):
- [ ] Добавить поле `plan_type` в БД
- [ ] Создать Edge Function `books-generate-free`
- [ ] Добавить Шаг 0 в визард: выбор тарифа
- [ ] Premium Upsell модалка

**Приоритет**: P0 - КРИТИЧНО

---

### Проблема 2: PDF рендерится через @react-pdf/renderer ❌

**Детали**:
- Клиентский рендеринг (нагрузка на браузер)
- Проблемы с Unicode (русский, грузинский → квадраты)
- Нестабильность при длинных книгах
- Разный рендер на разных устройствах

**Влияние**:
- 🐛 Баги Unicode: пользователи видят квадраты
- 📱 Нагрузка на мобильные: тормоза
- ❌ Некачественный PDF: жалобы пользователей

**Решение** (в Backlog):
- [ ] Создать Edge Function `books-render-puppeteer`
- [ ] HTML-шаблоны для разных стилей
- [ ] Встроенные шрифты (Noto Sans)

**Приоритет**: P0 - КРИТИЧНО

---

### Проблема 3: AI использует сырые записи ❌

**Детали**:
- AI получает полный текст записей (entries.text)
- Увеличивает стоимость токенов ×10
- Снижает скорость генерации
- Риск ошибок при длинных записях

**Влияние**:
- 💰 Стоимость: $X на книгу (дорого)
- ⏱️ Скорость: 40-60 сек (медленно)
- 📊 Качество: AI перегружается данными

**Решение** (в Backlog):
- [ ] Создать таблицу `entry_summaries`
- [ ] Обновить `books-generate-draft` для использования summaries
- [ ] Экономия токенов: ~90%

**Приоритет**: P0 - КРИТИЧНО

---

### Проблема 4: Нет Snapshot Layer ❌

**Детали**:
- AI не видит общую картину периода
- Нет эмоциональных графиков
- Нет динамики периода
- Нет агрегатов (active days, top topics)

**Влияние**:
- 📊 Качество книг: хуже (AI не понимает контекст)
- 🎯 Глубина анализа: низкая
- 📈 Тренды: не отслеживаются

**Решение** (в Backlog):
- [ ] Создать таблицу `monthly_snapshots`
- [ ] Создать Edge Function `snapshots-generate-monthly`
- [ ] Cron задача для автогенерации
- [ ] Интеграция с `books-generate-draft`

**Приоритет**: P0 - КРИТИЧНО

---
