## 🔄 Шаг 1: Перезапустите деплой в Vercel

**ВАЖНО**: После добавления переменных окружения нужно перезапустить деплой!

1. В Vercel Dashboard → **Deployments**
2. Найдите последний деплой (самый верхний)
3. Нажмите **⋯** (три точки справа)
4. Выберите **Redeploy**
5. Дождитесь завершения деплоя (обычно 1-2 минуты)

## 🧪 Шаг 2: Тестирование в приложении

### Тест 1: Создание PDF для новой книги

1. Откройте приложение: https://unity-wine.vercel.app
2. Войдите в систему
3. Перейдите в раздел **"Книги"** (Reports → Books)
4. Нажмите **"Создать книгу"**
5. Пройдите wizard (выберите настройки)
6. После создания книги откройте редактор
7. Нажмите **"Создать PDF"**
8. **Ожидаемый результат**: 
   - Появится toast "PDF книга создана!"
   - PDF должен появиться в библиотеке
   - При просмотре PDF должна быть правильная кодировка (кириллица отображается корректно)

### Тест 2: Проверка разных языков

1. Создайте книгу на русском языке
2. Создайте PDF
3. Проверьте, что кириллица отображается правильно
4. Повторите для других языков (если есть книги на других языках)

### Тест 3: Проверка настроек wizard

1. Создайте книгу с разными настройками:
   - **Layout**: photo_text, text_only, minimal
   - **Style**: warm_family, biographical, motivational
   - **Theme**: light, dark
2. Создайте PDF для каждой комбинации
3. Проверьте, что все настройки учитываются

## 🔍 Шаг 3: Проверка логов (если есть проблемы)

Если PDF не генерируется:

1. В Vercel Dashboard → **Deployments**
2. Выберите последний деплой
3. Перейдите в **Functions** → `/api/books/render-pdf`
4. Проверьте логи на наличие ошибок
5. Ищите префикс `[VERCEL-PDF]` в логах

### Частые ошибки:

**"Supabase configuration missing"**
→ Проверьте, что `SUPABASE_SERVICE_ROLE_KEY` добавлен правильно

**"Invalid access token"**
→ Проверьте, что используется правильный service_role key

**"Function timeout"**
→ Vercel Hobby plan имеет timeout 10 секунд. Для больших книг может потребоваться Pro plan (60 секунд)

**"Failed to launch browser"**
→ Проблема с Puppeteer/Chromium. Проверьте логи Vercel.
