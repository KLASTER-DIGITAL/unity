## 🎭 Роли пользователей

В UNITY существует 3 типа пользователей с разными уровнями доступа:

### 1. 🆓 Free User (Бесплатный)

**Доступ:**
- ✅ Создание записей (до 10 в месяц)
- ✅ AI-анализ записей (базовый)
- ✅ Просмотр истории записей
- ✅ Базовая статистика
- ❌ Offline режим
- ❌ Генерация PDF-книг
- ❌ Расширенная аналитика
- ❌ Мотивационные карточки (ограничены)

**База данных:**
```
profiles.is_premium = false
profiles.role = 'user'
```

**Ограничения:**
- Лимит 10 записей в месяц
- При превышении показывается Premium Modal

---

### 2. 💎 Premium User (Подписчик)

**Доступ:**
- ✅ Неограниченное количество записей
- ✅ Полный AI-анализ (GPT-4)
- ✅ Offline режим (IndexedDB / SQLite)
- ✅ Генерация PDF-книг
- ✅ Расширенная аналитика
- ✅ Все мотивационные карточки
- ✅ Push-уведомления
- ✅ Приоритетная поддержка

**База данных:**
```
profiles.is_premium = true
profiles.role = 'user'
subscriptions.status = 'active'
```

**Подписка:**
- Управляется через Stripe / внешние платежи
- Проверяется при каждом создании записи
- Автоматическая блокировка при истечении

---

### 3. 👑 Super Admin (Супер-администратор)

**Специальная роль для системного администрирования**

**Доступ:**
- ✅ Админ-панель (`/?view=admin`)
- ✅ Управление всеми пользователями
- ✅ Управление переводами (166 ключей, 7 языков)
- ✅ AI-аналитика (статистика OpenAI API)
- ✅ PWA управление (настройки, push)
- ✅ Системные настройки
- ❌ **НЕ имеет доступа** к обычному PWA-кабинету

**База данных:**
```
profiles.role = 'super_admin'
```

**Важно:**
- Супер-админ работает **ТОЛЬКО** в админ-панели
- Автоматический редирект при попытке открыть PWA
- Строгое разделение доступа (см. раздел [Функции супер-админа](#-функции-супер-админа))

## 🚀 Регистрация и онбординг

### Шаг 1: Выбор способа входа

Пользователь открывает приложение и видит Welcome Screen.

**Варианты:**
1. **Email + пароль** → Регистрация / Вход
2. **Google OAuth** → Быстрая регистрация
3. **Magic Link** (будущая функция)

### Шаг 2: Онбординг (4 экрана)

#### Экран 1: Приветствие
- Знакомство с UNITY
- Кнопка "Далее"

#### Экран 2: Имя и название дневника
- Поле "Как вас зовут?" → имя пользователя
- Поле "Название дневника" → персонализация (по умолчанию: "Дневник {имя}")
- Выбор эмодзи дневника 🏆 / 📔 / ✨ / 💪

#### Экран 3: Выбор языка
- 7 языков: Русский, English, Español, Deutsch, Français, 中文, 日本語
- Язык влияет на:
  - Интерфейс приложения
  - AI-ответы (GPT-4 отвечает на выбранном языке)
  - Мотивационные карточки

#### Экран 4: Первая запись
- Текстовое поле: "Опишите ваше первое достижение"
- **Важно:** Эта запись проходит AI-анализ во время регистрации
- Если оставить пустым → пропускается, можно создать позже

### Шаг 3: Создание профиля

После заполнения онбординга:

1. **Создается профиль** в таблице `profiles`:
   ```
   - user_id: UUID из auth.users
   - name: Имя пользователя
   - diary_name: Название дневника
   - diary_emoji: Выбранный эмодзи
   - language: Код языка (ru/en/es/de/fr/zh/ja)
   - role: 'user'
   - is_premium: false (по умолчанию)
   - created_at: Время регистрации
   ```

2. **Если указана первая запись** → AI-анализ + создание записи:
   - Текст отправляется на Edge Function `/ai-analysis`
   - GPT-4 анализирует текст (см. раздел [AI-обработка](#-ai-обработка-записей))
   - Запись сохраняется в таблицу `entries` с AI-полями

3. **Перенаправление** → Главный экран (Home)

## ✍️ Создание записи (Core Flow)

### Точка входа: Главный экран (Home)

Пользователь видит:
- **Header:** Аватар, название дневника, сетевой статус
- **Chat-стиль интерфейс:** Список предыдущих записей
- **Нижняя панель:** Поле ввода + кнопка отправки

### Процесс создания записи

#### 1. Пользователь пишет текст

```
"Сегодня закрыл крупную сделку на работе! 
Команда поздравила, начальник повысил премию. 
Чувствую гордость и мотивацию двигаться дальше."
```

Может добавить:
- 📸 **Фото/видео** (до 5 файлов)
- 🎤 **Голосовую заметку** (будущая функция)
- 🏷️ **Категорию** (по умолчанию AI определяет автоматически)

#### 2. Нажимает кнопку "Отправить"

Происходит следующее:

**A. Проверка лимитов (для Free)**
```javascript
if (!user.is_premium && entries_this_month >= 10) {
  // Показать Premium Modal
  return;
}
```

**B. Проверка offline режима**
```javascript
if (!navigator.onLine && !user.is_premium) {
  // Показать ошибку: "Offline режим только для Premium"
  return;
}

if (!navigator.onLine && user.is_premium) {
  // Сохранить в IndexedDB для синхронизации
  saveEntryOffline(entry);
  return;
}
```

**C. AI-анализ текста**

Запрос на Edge Function `/ai-analysis`:

```json
{
  "text": "Сегодня закрыл крупную сделку...",
  "userName": "Дмитрий",
  "userId": "uuid-123",
  "userLanguage": "ru"
}
```

GPT-4 анализирует и возвращает (подробнее в следующем разделе):
```json
{
  "sentiment": "positive",
  "category": "работа",
  "tags": ["сделка", "достижение", "карьера"],
  "reply": "Отличная работа, Дмитрий! 🎉 ...",
  "summary": "Успешное закрытие крупной сделки с повышением премии",
  "insight": "Твои упорство и профессионализм приносят результат...",
  "isAchievement": true,
  "mood": "гордость и мотивация"
}
```

**D. Сохранение в базу данных**

Запись сохраняется в таблицу `entries`:

| Поле | Значение | Описание |
|------|----------|----------|
| `id` | UUID | Уникальный ID записи |
| `user_id` | UUID | ID пользователя |
| `text` | String | Текст записи |
| `sentiment` | positive/neutral/negative | Эмоциональная окраска |
| `category` | работа | Категория (AI определяет) |
| `tags` | ["сделка", "достижение"] | Теги для поиска |
| `ai_reply` | "Отличная работа..." | Мотивационный ответ AI |
| `ai_summary` | "Успешное закрытие..." | Краткое резюме |
| `ai_insight` | "Твои упорство..." | Глубокий инсайт |
| `is_achievement` | true | Флаг достижения |
| `mood` | "гордость и мотивация" | Настроение |
| `media` | [image1.jpg, image2.jpg] | Прикрепленные файлы |
| `streak_day` | 5 | День серии (streak) |
| `focus_area` | работа | Фокус-область |
| `created_at` | 2025-10-29T10:00:00Z | Время создания |

#### 3. Пользователь видит результат

**На экране появляется:**


**Триггеры:**

## 🤖 AI-обработка записей

### Где происходит обработка

**Edge Function:** `supabase/functions/ai-analysis/index.ts`  
**API:** `https://[project].supabase.co/functions/v1/ai-analysis`  
**Модель:** GPT-4 (OpenAI API)

### Процесс анализа

#### 1. Получение текста

```typescript
const { text, userName, userId, userLanguage } = req.json();
```

#### 2. Формирование промпта

```typescript
const systemPrompt = `
Ты - AI-ассистент для дневника достижений.
Твоя задача - анализировать записи и давать мотивационные ответы.

Пользователь: ${userName}
Язык: ${userLanguage}

Проанализируй запись и верни JSON с полями:
- sentiment: "positive", "neutral", "negative"
- category: семья/работа/финансы/благодарность/здоровье/личное развитие/творчество/отношения/другое
- tags: массив тегов (максимум 5)
- reply: мотивационный ответ (2-3 предложения)
- summary: краткое резюме (1 предложение, до 200 символов)
- insight: глубокое понимание или совет (до 200 символов)
- isAchievement: true/false
- mood: описание настроения

Отвечай на языке: ${userLanguage}
`;
```

#### 3. Запрос к OpenAI

```typescript
const response = await fetch('https://api.openai.com/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${OPENAI_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    model: 'gpt-4',
    messages: [
      { role: 'system', content: systemPrompt },
      { role: 'user', content: text }
    ],
    temperature: 0.7,
    max_tokens: 1000
  })
});
```

#### 4. Парсинг ответа

GPT-4 возвращает JSON:

```json
{
  "sentiment": "positive",
  "category": "работа",
  "tags": ["сделка", "достижение", "карьера", "премия"],
  "reply": "Отличная работа, Дмитрий! 🎉 Закрытие крупной сделки и повышение премии — это значительные успехи. Твои упорство и профессионализм приносят результат. Продолжай двигаться вперёд!",
  "summary": "Успешное закрытие крупной сделки с повышением премии",
  "insight": "Твоя способность работать в команде и достигать целей делает тебя ценным профессионалом. Признание начальника подтверждает твой рост.",
  "isAchievement": true,
  "mood": "гордость и мотивация"
}
```

### Что делает AI

| Поле | Что анализирует | Пример |
|------|-----------------|--------|
| **sentiment** | Эмоциональная окраска текста | positive / neutral / negative |
| **category** | Тематика записи (9 категорий) | работа, семья, здоровье... |
| **tags** | Ключевые слова из текста | ["сделка", "достижение", "премия"] |
| **reply** | Мотивационный ответ (2-3 предложения) | "Отличная работа! 🎉 Продолжай..." |
| **summary** | Краткое резюме (1 предложение) | "Закрытие крупной сделки" |
| **insight** | Глубокий вывод или совет | "Твоя способность работать..." |
| **isAchievement** | Является ли достижением | true / false |
| **mood** | Настроение пользователя | "гордость", "радость", "тревога" |

### Fallback (если AI недоступен)

Если GPT-4 не отвечает или ошибка:

```javascript
const fallback = {
  sentiment: 'positive',
  category: 'Другое',
  tags: [],
  reply: 'Отличное начало! Продолжай вести дневник! 🎉',
  summary: 'Запись в дневнике',
  insight: 'Ведение дневника помогает лучше понимать себя.',
  isAchievement: false,
  mood: 'нормальное'
};
```

### Использование AI-данных

После получения AI-ответа, данные используются в:

1. **Раздел "Главная"** → Показывается AI-ответ под записью
2. **Раздел "История"** → Фильтрация по категориям и тегам
3. **Раздел "Достижения"** → Выборка записей где `is_achievement = true`
4. **Раздел "Отчеты"** → Статистика по sentiment, категориям, mood
5. **Поиск** → Поиск по тегам
6. **PDF-книги** (Premium) → Группировка по категориям, добавление insights

### Сценарий 2: Premium пользователь в командировке

**Персона:** Дмитрий, 35 лет, менеджер по продажам

#### Подготовка

1. Дмитрий — Premium пользователь
2. В **Настройках** включает **Offline режим**
3. Уезжает в командировку в регион с плохой связью

#### В офлайне (3 дня)

**День 1:**
1. Интернет пропадает → индикатор 🔴 Offline
2. Показывается бейдж "📴 Offline Mode"
3. Дмитрий создаёт запись: "Встретился с клиентом..."
4. Запись сохраняется в **IndexedDB** (Web) / **SQLite** (React Native)
5. Показывается toast: "Сохранено offline. Синхронизируется при появлении интернета"
6. AI-анализ недоступен → placeholder "Инсайт появится после синхронизации"

**День 2:**
1. Создаёт ещё 2 записи offline
2. Бейдж обновляется: "📴 Offline Mode (3)"

**День 3:**
1. Возвращается в город, интернет восстанавливается
2. Индикатор: 🔴 → 🟡 (syncing) → 🟢 (online)
3. **Автоматическая синхронизация:**
   - 3 записи отправляются на сервер
   - AI анализирует все 3 записи
   - Записи обновляются с AI-полями
4. Показывается **SyncCompletionModal:**
   ```
   ✅ Синхронизация завершена!
   
   Синхронизировано: 3 записи
   Не удалось: 0
   ```
5. Модалка закрывается через 2 секунды
6. Дмитрий видит все свои записи с готовыми AI-инсайтами

#### Задача 1: Найти конкретного пользователя

2. Вводит в поиск: "dmitry@example.com"

   - 47 записей
