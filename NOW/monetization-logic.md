## 💎 Модель монетизации

### Freemium

UNITY использует модель **Freemium**:
- **Free** — полный функционал БЕЗ AI анализа (неограниченные записи)
- **Premium** — полный функционал С AI анализом за **$4.99/месяц** или **$49.99/год**

**Ценностное предложение:**

```
За $4.99/месяц пользователь получает $15+ ценности:
• AI анализ записей ($5.00)
• Offline режим ($3.00)
• PDF-книги с AI ($2.50)
• Премиум-темы ($1.50)
• Экспорт/импорт базы ($2.00)
• Приоритетная поддержка ($2.00)
```

**Стратегия:**
- 7 дней бесплатного триала
- Conversion rate: 15% (Free → Premium)
- LTV: $60 (12 месяцев средняя подписка)

## 🔐 Как работает проверка Premium

### 1. Проверка в базе данных

**Таблица:** `profiles`

```sql
SELECT 
  id,
  name,
  email,
  is_premium,
  role,
  created_at
FROM profiles
WHERE id = $1;
```

**Результат:**
```json
{
  "id": "uuid-123",
  "name": "Дмитрий",
  "email": "dmitry@example.com",
  "is_premium": true,    ← ключевое поле
  "role": "user",
  "created_at": "2025-09-01T10:00:00Z"
}
```

### 2. Проверка при создании записи

**Файл:** `src/features/mobile/home/components/chat-input/messageHandlers.ts`

**Логика:**
```typescript
// Получаем данные пользователя
const isPremium = userData?.profile?.isPremium || false;

// Если НЕ Premium
if (!isPremium) {
  // Считаем записи за текущий месяц
  const count = await getEntriesCountThisMonth(userId);
  
  // Если >= 10
  if (count >= 10) {
    // Показываем Premium Modal
    setShowPremiumModal(true);
    
    toast.error("Лимит бесплатных записей исчерпан");
    return; // Блокируем создание записи
  }
}

// Если Premium или лимит не превышен
await createEntry(entryData);
```

### 3. Проверка Offline режима

**Файл:** `src/shared/lib/offline/helpers.ts`

**Функция:** `canUseOfflineMode(userData)`

**Логика:**
```
Проверка 1: Пользователь залогинен?
    НЕТ → "Войдите в систему"
         ↓
Проверка 2: Есть Premium?
    НЕТ → "Offline режим доступен только для Premium"
         ↓
Проверка 3: Включен в настройках?
    НЕТ → "Включите Offline режим в настройках"
         ↓
    ДА → Разрешить использование offline
```

**В коде:**
```typescript
// Settings → Offline режим
const handleOfflineToggle = (checked: boolean) => {
  const check = canUseOfflineMode(userData);
  
  if (!check.allowed) {
    if (check.reason === 'premium_required') {
      // Показываем Premium Modal
      setShowPremiumModal(true);
    }
    return;
  }
  
  // Включаем offline
  setOfflineEnabled(checked);
};
```

### 4. Проверка PDF-генерации

**Где:** Раздел "Отчеты" → кнопка "Генерировать PDF"

**Логика:**
```typescript
const handleGeneratePDF = async () => {
  if (!userData.isPremium) {
    toast.error("PDF-книги доступны только для Premium");
    setShowPremiumModal(true);
    return;
  }
  
  // Генерируем PDF
  await generatePDFBook(userId, dateRange);
};
```

```

│                                      │
│ 💵 MRR: $1,167.66                    │
│    (234 × $4.99)                     │
│                                      │
│ 📊 ARR: $14,011.92                   │
│    (MRR × 12)                        │
│                                      │
│ 🔄 Churn rate: 3.2%                  │
│    (8 отмен / 234 активных)          │
└──────────────────────────────────────┘
```

**SQL для расчёта:**
```sql
-- MRR (Monthly Recurring Revenue)
SELECT COUNT(*) * 4.99 as mrr
FROM profiles
WHERE is_premium = true AND role = 'user';

-- Conversion rate
SELECT 
  COUNT(*) FILTER (WHERE is_premium = true) * 100.0 / COUNT(*) as conversion
FROM profiles
WHERE role = 'user';

-- Churn rate (отмены за месяц)
SELECT 
  COUNT(*) FILTER (WHERE status = 'cancelled' AND updated_at >= DATE_TRUNC('month', CURRENT_DATE)) * 100.0 /
  COUNT(*) FILTER (WHERE status = 'active') as churn
FROM subscriptions;
```

   ```javascript
   const product = await stripe.products.create({
     name: 'UNITY Premium',
     description: 'Полный доступ к функциям дневника достижений'
   });
   
   const priceMonthly = await stripe.prices.create({
     product: product.id,

     currency: 'usd',
     recurring: { interval: 'month' }
   });
   
   const priceYearly = await stripe.prices.create({
     product: product.id,
     unit_amount: 4999, // $49.99
     currency: 'usd',
     recurring: { interval: 'year' }
   });
   ```

2. **Создание Checkout Session:**
   ```typescript
   const handleGetPremium = async () => {
     const session = await createStripeCheckout({
       userId,
       priceId: 'price_monthly', // или 'price_yearly'
       successUrl: 'https://unity-wine.vercel.app/?payment=success',
       cancelUrl: 'https://unity-wine.vercel.app/?payment=cancel'
     });
     
     window.location.href = session.url;
   };
   ```

3. **Оплата в Stripe:**
   - Пользователь вводит карту
   - Stripe обрабатывает платёж
   - Webhook отправляется на сервер

4. **Webhook обработка:**
   ```typescript
   // Edge Function: /stripe-webhook
   
   if (event.type === 'checkout.session.completed') {
     const session = event.data.object;
     
     // Активируем Premium
     await supabase
       .from('profiles')
       .update({ is_premium: true })
       .eq('id', session.metadata.userId);
     
     // Создаём подписку
     await supabase.from('subscriptions').insert({
       user_id: session.metadata.userId,
       plan: session.metadata.plan,
       status: 'active',
       stripe_subscription_id: session.subscription,
       stripe_customer_id: session.customer,
       start_date: new Date(),
       end_date: new Date(+new Date() + 30 * 24 * 60 * 60 * 1000)
     });
   }
   ```

5. **Редирект и активация:**
   - Пользователь возвращается в приложение
   - Показывается Success Modal: "Premium активирован!"
   - Premium функции разблокируются

-- MRR (Monthly Recurring Revenue)
SELECT COUNT(*) * 4.99 as mrr
FROM profiles
WHERE is_premium = true AND role = 'user';

-- Conversion rate
SELECT 
  COUNT(*) FILTER (WHERE is_premium = true)::numeric / COUNT(*) * 100 as conversion
FROM profiles
WHERE role = 'user';

-- Churn rate (за последние 30 дней)
SELECT 
  COUNT(*) FILTER (WHERE status = 'cancelled' AND updated_at >= NOW() - INTERVAL '30 days')::numeric /
  COUNT(*) FILTER (WHERE status = 'active') * 100 as churn
FROM subscriptions;

SELECT COUNT(*) as new_premium
FROM profiles
WHERE is_premium = true
  AND premium_activated_at >= DATE_TRUNC('month', CURRENT_DATE);
